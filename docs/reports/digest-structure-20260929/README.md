## 初回実走で検出した音声の接続不具合

初回の採用区間抽出では、2区間目のPCMサンプル数は一致したが独立抽出とのbyte照合が不合格になった。
音声の途中読込み起点を変えると、同じ40,230,960 bytesでも実サンプル値が変わることを確認した。
冒頭からの音声だけの復号を基準にすると、区間の先頭付近に限らず差が点在した。
そのため、任意の先読み秒数を追加して合格扱いにはしない。

限定修正は、映像の採用区間抽出を維持し、音声を元素材の冒頭から復号して絶対サンプル位置で取り出すこと。
必要区間の音声だけを保存し、全素材のPCMやproxyは作らない。
失敗した実走の証拠と旧区間媒体は保持する。生成済み映像2区間はencoded packetをcopyし、新しい音声との媒体へ組み直す。
AAC内部のどの状態が原因かは未断定だが、復号開始位置への依存は実測で確認済み。
