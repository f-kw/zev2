# HRC-001・002 — Panel の実描画と保存の独立検査

Codexです。これは Panel 内の文字位置、有限の背景選択、保存後の状態復元を確認する技術検査です。人間による見た目の採否は未判定です。

## 結果

**v006 は終了コード 0、4 件すべて成功しました（3 子試験と親試験）。実行時間は 186.1 秒です。** 保存・再読込・通常字幕への固定・自動案への復帰、不正な背景指定の拒否、実際の文字輪郭による中央配置、背景 3 種の描画、120 フレームの完成動画と最終検査まで確認しました。

採用済みの通常字幕「逃げるんだ」は、保存済み入力を本番と同じ経路で描き直し、旧 PNG と実バイトおよび全 RGBA 画素が一致しました。音声パケットの内容も合成前後で一致しました。v005 で見つかった校正参照名の重複は修正され、v006 では校正元領域を独立に取り直す検査も含めて通過しています。

## 検査する内容

- 短文「逃げるやつ?」、横長文「なんかグロいやつに捕まってる」、2 行文「先に条件を伝える／それから進める」を、無地・方眼紙・コミック枠の 3 種で描く。9 枚の Panel と対象外の通常字幕 1 枚を、1920×1080、30 fps、120 フレームの合成動画へ通す。
- 各行の実際の文字輪郭を画像から取り出し、Panel の左右余白と、全行を合わせた文字領域の上下余白を比較する。整数画素への丸めによる対向余白差 1 px 以内だけを許す。見た目の採点係数は設けない。観測した行を 2 px ずらした場合は検査が拒否することも確認する。
- 背景を変えても文字の画素・Panel の寸法が一致し、3 種の背景画像は互いに異なることを確認する。文字のない内部に透明な穴がなく、方眼紙とコミック枠には空間的な模様があることを確認する。
- 背景変更、通常字幕への固定、自動案への復帰を、それぞれ保存して読み直す。本文・明示改行・表示開始と終了・変更対象外の字幕、および元の自動案の実バイトを保持する。
- 未登録の背景、任意の画像ファイル、外部 URL、背景値の改変を拒否する。保存できなかった 8 件では出力ファイル自体が作られないことも確認する。
- 完成動画の最終検査、120 フレーム、音声パケットの内容保持を確認する。

検査用映像・音声はローカルの合成素材です。背景の方眼紙・コミック枠はローカルで作成された有限の SVG 素材で、出自と内容ハッシュを保存しています。外部 API 通信・外部素材取得・費用支出はありません。

## 実行と失敗の保持

試験は [専用テスト](/private/tmp/zev-stage4-editing-20260918/worktree/evals/clip_composition/presentation_panel_quality_v002.test.mjs) 1 本です。保存・拒否・実描画の 3 子試験と、それらを束ねる親試験で構成します。

|版|結果・修正内容|
|---|---|
|v001|制限環境がローカル待受けを拒否。通常の承認経路でネイティブ実行へ移行。|
|v002|旧通常字幕との一致を確認。検査用の単独 React 表示が、画像読込みに必要な Remotion の実行環境を欠いて失敗。検査設営修正 1 回目。|
|v003|検査用の依存探索設定が既定の検索先を欠いて失敗。検査設営修正 2 回目。|
|v004|独自の撮像アダプタで旧通常字幕との画素差を検出。期待値を変更せず、本番の描画・入力作成・子処理記録へ統一。検査設営修正 3 回目。|
|v005|本番経路の旧通常字幕一致と保存・拒否が成功。120 フレームの再合成が一致。校正行の参照名重複により最終検査で停止。製品側の受け渡しを修正し、v006 で解消を確認。|
|v006|本番描画から最終検査まで成功。9 枚の Panel の実画素位置と背景差、通常字幕の画素不変、120 フレーム、音声内容保持を確認。|

すべての版を固有の出力ディレクトリへ保存し、失敗した版を上書きしていません。v005 は 162.5 秒、保存と拒否の 2 子試験が成功、実描画の子試験と親試験が失敗でした。実行中に追加された校正領域の独立再導出は、開始時に読み込んだ v005 の検査実装には含まれません。
