- **HRC-001**：Panelも、フォントの行の箱ではなく、描かれた各行の輪郭と全行のまとまりを背景板の中央へ揃える。横位置は各行、縦位置は全行のまとまりで扱う。特定字幕への補正値は持たない。通常字幕の位置・本文・改行・表示期間を保持する。
- **HRC-002**：無地に加え、ローカルで作成した方眼紙とコミック枠のSVG背景を有限候補へ追加。背景画像の由来・識別・SVG byteを描画規則へ含め、保存・再読・一件修正・CLI表示・画面選択へ接続した。任意画像path・自由な描画値は受け付けない。自動選択の許容集合は今回増やさず、背景違いの短尺は手で選んだ試作として示す。
- **HRC-003**：保存済みの動作とPNGを調べ、Bounce／Pulseのサイズが隣接frameで16pxずつ変わる箇所へ、その既存端点の中間サイズを追加。該当差は8pxになり、最大状態・発火時刻・音声ピーク・表示期間・静止復帰を保持する。Shakeの動作は不変。人間の原回答は動き系へのまとまった指摘であり、原因presetを本人が指定したとは記録しない。
- **Q2**：固定HTML・CSS・再生／回答処理とBatchデータを分離。問いと対象範囲を表示し、一つの動画プレイヤーで区間再生・再開・前後拡大・必要な比較・ポイント移動を行う。初期回答は未回答。端末保存、回答ファイルの取り出し／再読、チャット原文を同じポイントへ記録する入口を持つ。「良い」を機能使用許可や課題完了に変換しない。

Panelで実測した位置補正は、校正用の行画像・元の描画設定へ束縛する。完成媒体検査の準備でも画像を再読し、既存レイアウト検査で板の領域を独立に再導出してから補正を再計算する。板だけを取り除く比較画像にも同じ文字配置を保つ。複数字幕・複数行の校正根拠には、それぞれ異なる識別を割り当てる。
