次の教師は、過去に提示した動画を再利用せず、新しく取得する。承認済み配信者の切り抜きに限定し、縦型ショートかつ演出の種類が多いものを優先する。人間へ見せる前に機械側で候補を絞り、同時に提示するのは1本だけとする。

通常動画とショート動画は、最初から別の形式として記録する。5本到達後に文法案を起草する場合も、通常動画だけの観測、ショート動画だけの観測、両方で反復した観測を分ける。両形式で確認できるまでは「共通文法」と判定しない。

## 分かったこと

1. 演出の中心は、派手な特殊効果の数だけではなく、発話を読みやすく楽しく見せるテロップ運用にある。
2. テロップは発話を意味の読める短い単位に分け、発話の進行に合わせて切り替える。長文を収めるために文字を自動縮小するのではなく、改行と表示単位で処理する方向が有力である。
3. コメント、ナレーション、複数話者、笑い声・泣き声・無音は、通常の本人発話と同じ表示契約にしない。
4. 発言の意味や感情に応じて、書体、色、大きさ、位置、傾き、振動、移動、SE、ズームを選び分ける実例がある。
5. 同じ「強い感情」でも、大きい文字を重ねる場合と、文字を出さず顔アップだけにする場合がある。感情と演出を一対一で固定できない。
6. 必要な素材が元配信内ですでに完成している場合は、新規生成せず、その素材を選択して接続する構成がある。
7. 一作品だけの固有着想を規則化すると、同じ着想しか作れない機能になる。複数動画で反復した関係だけを一般文法候補にする必要がある。

## 仮説の現在地

- 裏付けが得られたもの: 発話テロップ、意味単位の分割、大きく読みやすい文字、発話進行に合わせた切替。
- 部分的に裏付けられたもの: コメントを通常発話と異なる背景板や見た目で表示する型。
- 修正が必要なもの: 「文字サイズは常に一定」。長文収容のための自動縮小は禁止しつつ、意味上の強調として一時的に大きくする例がある。
- 未確定のもの: 演出の優先順位、複数演出が競合した場合の選択、演出をあえて付けない条件、動画内の統一規則、各演出の数値。

## 次の進め方

1. ホロライブ系・壱百満天原サロメ・小森めとの切り抜きから、過去4本とは異なる動画を新規取得する。
2. 縦型ショートを優先し、テロップ、ズーム、SE、画像、背景板、画面構成など複数種類の演出が観察できそうなものを機械側で先に選ぶ。
3. 人間へ提示するのは1本だけとし、同じ教師を再提示しない。時間計測は行わない。
4. 各教師と各観測に「通常動画 / 縦型ショート」の形式を必須記録し、集計と文法候補を分離できる状態を維持する。
5. 5本目の視聴メモを保存した後、通常動画の観測、ショート動画の観測、両形式で反復した観測を分けたYES/NO文法チェックリスト案を作る。
6. 蒸留案を人間へ戻し、承認前に演出実装へ進まない。
