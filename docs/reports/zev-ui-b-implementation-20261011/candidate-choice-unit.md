## 結果・平易な説明

**この画面で選ぶのは、動画全体に入れる一つの場面です。選んだ一場面だけに動画全体を置き換える画面でも、完成構成案を何案も選ぶ画面でもありません。** 通常は推奨された複数場面の構成で進み、必要なときだけ保存済みの個別シーンを見ます。

確定PDFは、この選択対象と、閲覧だけでは採用を変更しないことを定めています。一方、「現在のどの場面と差し替えるか」「追加/除外のどちらを行うか」「複数場面を一括選択するか」までは画面にありません。前報告の二択は、画面で触る単位と正式保存する単位を分けると整理できます。

- 画面で触る単位：保存済みのシーン候補一つ。
- 正式に保存・再照合する単位：その変更を反映した動画全体の採用集合と構成の新版。

**推奨は、全体の採用集合へ一場面の明示変更を反映し、他の採用場面を勝手に消さない方式です。** B案の「採用案に反映する」の最小解釈は、まだ採用していない選択候補を構成へ入れること。すでに採用中なら変更なしと表示します。差替えや除外をこのbuttonの裏で自動推定しません。除外/差替えが必要なら対象を明示する別の操作が必要であり、PDFから今回の必須実装と断定しません。

例えば、推奨構成が「話のきっかけ→考え方の変化→最後のまとめ」のとき、別の保存場面を採用しても、この三場面を無断で消しません。更新後に何を加え、何が残るかを構成全体で確認し、変更後資料が揃ってから作成前確認へ進みます。単一場面差替え方式を採るなら、先に「考え方の変化をこの場面へ差替える」のような対象指定が必要です。

これは本人へレイアウト採否を再質問する事項ではありません。選択対象は確定PDFで分かるため、親はB案の意味を保つ最小接続として上記の反映単位を判断できます。明示的人間選択を正式Digest計画へ渡す新しい記録/再準備のcontract境界は、前報告どおり実装前に確認します。
