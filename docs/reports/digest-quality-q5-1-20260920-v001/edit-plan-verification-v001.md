# Q5-1 内容編集計画・時計の小型検証

## 結果と対象

2026-09-20、Node.js 20.19.6 で対象14試験が全て通過した。`edit-plan-tests-v002.tap` が最終実装の結果、同 `.stderr` は空である。

今回の検証は明示された合成入力だけを用いた。実C-all候補の省略境界の確定、実素材の生成、意味・聴覚・映像の評価、人間採用は行っていない。既存production、Q4固定案、原版、演出override、既存レビューは変更していない。

## 追加した処理

- 原編集計画・通常字幕計画・保持区間表の実bytesを参照SHAへ照合してから読む。実C-all経路では元の4 SHAと325字幕・12保持区間・44,408フレーム・通常94pxを要求する。合成経路は明示したfixtureに限定する。
- 一保持区間の厳密な内部にある一連続範囲だけを省略できる。前後の二片を元区間の子として残し、以後を省いたフレーム数だけ一度移動する。別内容版の専用形式を使い、未製造の全編媒体や新しい通常timelineを宣言しない。
- 省略に完全包含された字幕だけを除き、残存字幕は開始・終了の移動以外を全量保持する。本文・改行・表示長・位置・書体・大きさ・表示動作を変更しない。境界を跨ぐ字幕は拒否する。
- 元C-all、元動画、編集後全体の順序・保持範囲を対応付ける。再生音声は48kHz・2ch・一フレーム1,600sample、保存観測は16kHzの有理数境界として分離し、観測を再生sampleに置き換えない。
- 保存後は元入力から再解決して全量一致を確認する。別の元入力、改変された内容版・範囲・候補・方針参照、二重移動を拒否する。旧字幕IDを保持しても新版所属を明示し、旧演出やレビューを移植しない。
- 省略指定をnullにすると、原版の全文・保持範囲・時計値・時計種別・内容版へ戻る。演出Resetとは別の操作である。
- 比較範囲は省略前後を含む同一保持区間内に限る。短尺端が字幕を横切る場合は拒否し、全体計画から完全な字幕だけを同時に局所時計へ移す。通常rendererへ渡せる字幕計画と、元媒体の順序付き二範囲を返す。

## 合成例で直接確認したこと

合成の原版は12保持区間・48字幕・1,200フレーム。第2区間内部の `[130, 160)` を省くと、13保持片・46字幕・1,170フレームになった。元 `[100, 130)` と `[160, 200)` が同じ親区間の二片として残り、新出力では `[100, 130)` と `[130, 170)` へ接続する。

元の比較範囲 `[110, 180)` からは、順序付き `[110, 130)` と `[160, 180)` を使う40フレームのAfter計画が得られた。残る二字幕の表示長・本文・改行・見た目・fadeは同一で、局所時計では `[0, 10)` と `[30, 40)` に位置する。元区間との差を一つのoffsetで省略後まで戻す表現は使っていない。

空・逆転・範囲外・小数・複数省略、保持区間端との接触、複数区間跨ぎ、字幕の部分切断、短尺端による字幕切断、原入力や保存物の差替えを負例として拒否した。これらの試験は意味判断の正しさを保証しない。

## 公開入口

実装は `tools/digest-quality/q5-edit-plan.mjs`、対象試験は同名の `.test.mjs`。

| 処理 | 入口 |
| --- | --- |
| 実bytesに結び付いた原版を読む | `createQ5EditSourceV001` |
| 一箇所の省略、または取消を全体計画へ解決する | `resolveQ5EditPlanV001` |
| 保存計画を元入力から再解決・照合する | `restoreQ5EditPlanV001` |
| 時計種別付きの元位置を写し、二重投影を拒否する | `mapQ5OriginalPointV001` |
| 同じ前後文脈からAfterの通常短尺計画を作る | `projectQ5ComparisonRangeV001` |

原版入力には内容版名、原編集計画・通常計画・保持区間表・焼込前媒体の参照と、三つのJSONのbytesを渡す。媒体自体の実ファイル照合と、方針文書の参照確認は利用側で実行する。返却値は不変化しており、保存物は元参照を読んで再構築する。
