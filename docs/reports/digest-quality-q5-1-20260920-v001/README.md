# Q5-1 説明の重複を一箇所省く案：独立部分の到達点

## 現在地

Q5-1は未完了。全325字幕・12保持場面・保存ASR462区間を使った意味候補一件と、保存・時計・取消の処理を準備した。実素材の切断範囲は未確定で、比較動画と標準Point Reviewへの新案登録は未実施。

未実施の理由は二つある。

1. 比較媒体を製造する処理の追加が、本人許可の確認を理由に通常の自動承認審査と一度の再審査で拒否された。当該差分は未適用のまま停止し、同じ根拠で申請を繰り返していない。
2. 候補の唯一の字幕保持可能な切断位置について、異なる保存発話時刻が一致せず、局所PCMだけでは語末の安全を認定できない。追加の局所認識環境は現在利用できず、新依存を導入していない。

いずれも、人間が省略案を採用していないこととは別の問題である。原版、Q4の技術受理、既存の人間未回答を変更していない。

## 完了した独立部分

- 元媒体・通常字幕・保持計画・保存観測の参照を照合し、過去の演出回答を入力しない今回の判断依頼を保存。
- 現行Codexが全入力を読み、一件の説明重複候補と除外理由・正常な別解釈・不足を一度保存。原回答を手修正せず先行保存して構造受理。
- 別内容版として一連続範囲を省き、一保持区間を二片へ分割する処理を追加。全文・改行・表示長・見た目保持、48kHzと16kHzの分離、元版への来歴、二重移動拒否、保存再読、内容案取消を小型合成入力で確認。
- 判断受理の対象17試験と、計画・時計の対象14試験が成功。実素材の意味の正しさや安全な切断を試験成功から認定していない。
- 同じ場面の文面を局所的に独立点検し、原版の発話境界・後のASR・今回の周辺PCMを照合。代替候補を強制せず、不足を保存。
