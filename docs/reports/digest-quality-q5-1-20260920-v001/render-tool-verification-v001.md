# Q5-1：短尺比較媒体の補助処理と小型検証

## 完了した範囲

本人の[限定実施承認と通常審査の記録](permission-review-v001.md)に基づき、[補助処理](../../../tools/digest-quality/q5-render.mjs)と[直接関連する小型試験](../../../tools/digest-quality/q5-render.test.mjs)を追加した。既存の描画・媒体製造・共通品質検査は変更していない。

**合成媒体での実装・接続検証は完了。実C-allの比較動画は未生成。** 現在の省略候補の切断位置には根拠不足が残るため、実候補の描画命令、比較動画、Point Reviewを作成していない。今回の成功を省略の意味的な正しさ、人間の採用、元版の置換へ読み替えない。

## 処理の内容

1. 元C-allの媒体・通常字幕・保持計画の固定した実ファイルを照合し、保存した別内容案を元入力から再解決する。元通常完成版は必要区間への参照として使う。合成入力を実素材用の入口へ通す条件変更はしていない。
2. 残す二つの連続範囲を既存の背景抽出処理で取り出し、映像と音声を別々に連結する。字幕描画前の保持画素と48kHz・2chの音声を、全byte・元の順序で独立照合する。二片の音声を映像尺へ自動で埋める処理は使わない。
3. 照合済みの音声から新しいAACを製造し、通常94pxの完全な字幕を既存描画へ渡す。Q4の演出案・修正・古い人間回答は渡さず、新しい意味判断を実施したとも記録しない。
4. 短尺全体の厳密再現、字幕の実描画による識別、既存の共通品質検査、新しい基礎音声と字幕完成版の圧縮音声・論理復号音声の保持を確認する。入力と実装の再照合まで通った後、既存の未使用出力先への公開処理を使う。

指示根拠の参照も実ファイルまで照合し、公開前の再照合に含めた。元参照との同一性は場所とSHAで照合し、任意のbyte数を付けた場合は別途実値へ照合する。共有描画ルールの対象は変更せず、追加の補助処理と依存実装を別の実参照として保存した。

初回では、二片の全画素・両音声ch、新AACの提示時計、順序反転、右chの1標本変更、余剰・不足音声、16kHz観測時計の混入、参照差替え、出力上書き、指示根拠の変更、合成媒体の実素材入口への混入、任意byte数付き参照、別媒体・通常以外の接続を確認した。

共通描画は1920×1080・30fps・36frame・通常94pxの合成字幕1件を使用した。18frameずつの二片から既存の基礎映像製造、字幕描画、共通品質検査まで同じ処理を実行した。未対応の字幕配置を与えた負例では、失敗記録が残り、最終出力先は作られなかった。

| 実測 | 結果 |
|---|---:|
| 保持画素の比較 | 36frame・111,974,400 byte一致 |
| 符号化前の音声比較 | 57,600標本・460,800 byte一致 |
| 新AACの開始補償 | 1,024標本を分離、提示開始0 |

符号化前の一致と、新しいH.264／AACへの変換後を区別する。実C-allの元AACとの全一致や、変換後の差が省略区間だけに局在することは要求・主張していない。
