### 容量の境界

- 307枚分の展開RGBAを同時に持つと `307 × 1920 × 1080 × 4 = 2,546,380,800 bytes`。これは画素payloadの算定で、PNGファイル容量やprocess全体RSSではない。今回の描画は状態を逐次処理する。

- 新しい容量閾値をCodex判断で置かない。全編実行時には実入力・具体的製造方式に応じた容量と権限の確認が必要。現在の準備PNG実測は結果欄に記録する。
