# 6＋13.3 人間確認結果 — 新素材Digest初見 / 字幕色

実施日：2026-09-28  
対象：新素材Digest 15:31.633 と既存字幕色A/B/C比較  
位置付け：人間初見結果。AIによる問題候補提示より先に確認した一次評価。

## 1. 結論

新素材Digestは技術的な字幕同期・既存アニメーションには大きな違和感がなかった。一方、製品品質上の主要課題は字幕の可読性・分割と、Digestとしての構成ルールにある。

次の最優先は字幕可読性・分割。字幕タイミングと既存アニメーションは今回の感想を根拠に先に変更しない。

字幕色では比較用の水色は肯定され、「もっとカラフルでもよい」という方向性が明示された。追加色の有限palette化は候補に進める。一方、強調箇所変更Bの優越は明示的に確認されていないため、その変更を採用済みとは扱わない。

## 2. 字幕で直すこと

- 現状は「字幕サイズ」に見え、文字が小さい。文字サイズを大きくすることを最優先する。
- 一回に表示する文字量が多い。1行を標準とし、2行は例外的にする。
- 2行が必要な場合でも、文字を小さくして収めるのではなく大きさを優先する。
- 画面端との余白は絶対条件にしない。クリップしないことは守るが、余白確保のために文字を小さくしない。
- ゆっくり話す箇所では長い字幕を一枚に保持せず、意味と発話速度に合わせて分割する。
- 白文字＋太い黒単色の枠は使わない。現行の黒枠は太く、白黒コントラストが強すぎる。より細く、よりマイルドな色・見え方へ再設計する。
- 字幕タイミングと現在のアニメーションには特に違和感なし。今回の主要修正対象にしない。

文字数の固定上限だけで解決せず、実フォント幅・表示行数・発話速度・意味境界を併用する。2行化を先に選んで小さく縮小する設計は禁止する。

## 3. Digest構成で直すこと

- 「今から何をやるか」という宣言・導入が素材中にあり、Digestの理解に有効なら入れる。
- グッズ紹介とスパチャ読みは原則除外する。今回テーマや内容に直接関係する場合のみ残してよい。
- ゲーム終了・本編終了が素材にある場合、可能なら終端へ入れる。元動画の締めをDigestの締めとして活用する。
- OP/EDはDigestらしさを作るバリエーション候補。常時強制せず、素材に自然なものがあれば使う。
- 表情変化をアップにする演出は将来候補。ただし字幕可読性・分割より優先しない。

## 4. 字幕色

人間回答：

- 水色は良い。
- もっとカラフルでもよい。

したがって比較専用だった明るい水色は採用候補として次工程へ進めてよい。黄色＋水色だけを永続的な2色上限にはしない。ただし自由RGBや無制限な色生成にはせず、有限paletteとして設計・検証する。

A→Bの強調箇所変更について明示的な肯定回答は得ていない。追加の長尺比較を要求せず、今回は強調範囲変更を採用根拠ありとは扱わない。

## 5. 人間確認方式の是正

今回のA/B/Cでは「一箇所の差を見るために46.167秒を3回見る」負担が発生し、人間確認方式として不適切だった。

今後の原則：

- 一つの局所差なら、その差が判断できる最短の前後文脈だけ提示する。
- 原則は数秒〜十数秒程度。必要な文脈が長い場合だけ延長する。
- A/B/C全体を同じ長尺で3回見せない。
- 可能なら同じ短区間をA/B切替、連続比較、または差分対象だけで確認する。
- 人間確認時間そのものを製品コストとして扱う。
- 既に明示回答が得られた事項を再確認しない。
