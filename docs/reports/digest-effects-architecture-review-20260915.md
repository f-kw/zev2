## 採用された前提

目的は演出数を増やすことではなく、普通の部分を安定して見せながら、内容上の山、短い強い発話、反応に自然な変化を付け、一本としての単調さを減らすこと。過剰演出に加え、変化する意味がある場面まで通常表示のままになり、全体が平坦になることも失敗として扱う。人間が個々の演出を一件ずつ選択・承認する運用にはしない。

1. 演出は、確定字幕から描画計画を作った後、物理表示QCの前へ接続する。
2. 対象は、意味上の字幕参照ではなく、実際に画面へ表示する各字幕の既存IDで指定する。
3. 演出は、Prospect採否、保持区間、字幕本文、字幕時刻、並び順、元動画対応を変更しない。
4. 指定なし、空指定、全件normalでは現行経路と同じ状態へ戻れることを保証する。
5. `focus` / `vocal_accent`という役割と具体的な見た目を分け、見た目はrenderer側の有限presetで実現する。
6. 自動配置は、新しい「演出意図の選択」として扱う。既存の字幕区切りSkillがそのまま演出を判断できるとは扱わない。
7. 音響センサー群はPhase 1・2で先行開発せず、自動配置で必要性が確認されたものだけ追加する。
8. 後段の抑制は重複・競合の整理を担当する。単純な間隔や件数上限で、意味のある山を一律に削らない。独自の係数や重み付けを追加しない。
9. 選択、抑制理由、判断未完了を、問題区間の原因調査に使う内部記録として残す。人間の全件確認リストへ変換しない。
10. transitionは初期工程へ混ぜない。
11. Step 2の既存試作は参考実装とし、現在の設計へそのまま昇格させない。

## 現物に基づく実装上の判断

### 接続位置と最小の指定

既存の[ダイジェスト製造経路](../DIGEST_V1.md)は、保存済みの候補・保持判断・字幕判断から、基礎映像と字幕を製造する。演出を表示側へ追加すれば、上流の採用や内容を再判断する必要はない。[既存architecture](../architecture/ZEV_AGENT_SKILL_ARCHITECTURE_v001.md)の意味判断と出力判断の責務分離にも合う。

最小案は、対象の確定字幕・描画計画の版へ結び付けた「表示字幕IDと役割」の小さな指定を、描画入力として渡すこと。本文・時刻を複製した新しい編集計画は作らず、既存IDから解決する。

完成ダイジェストでは、[字幕の投影処理](../../evals/clip_composition/digest_v1_phase2_caption_bridge.mts)が意味上の参照と表示字幕ごとのIDを別に持つ。意味上の参照だけでは、個々の表示字幕を特定できない。

### 再利用できる能力と必要な追加

[共通描画計画の生成](../../evals/clip_composition/run_presentation_instruction_renderer_job_v002.ts)は、表示字幕ごとの見た目を表現できる。一方、通常の計画生成は全字幕へ同じ見た目を設定しており、通常の製造入口からStep 2の演出指定を引き渡す配線もない。

保存済みの基礎映像・音声・時間軸、確定字幕・改行・元動画対応、共通描画計画、字幕画像生成・映像合成、表示領域・実画像検査、通常の映像・音声QCは再利用できる。追加は、小さな役割指定、参照と禁止項目の検査、描画への引き渡し、演出後の表示検査への接続が中心となる。

Phase 1・2に新しいSkillや大型schemaは不要。ただし、役割の列挙、対象ID、重複、対象版との一致を検査する型と検証処理は必要。既存の厳密な入力検査へ、未定義の項目を勝手に追加する構成にはしない。

### 会話・全体文脈と音響情報

[意味区切りSkill](../../runner/src/skills/caption-meaning-grouping-v001.ts)は確定発話の区切りを、[表示区切りSkill](../../runner/src/skills/caption-display-boundaries-v001.ts)は字幕と行の切替を判断する。演出の要否・役割・主対象を選ぶ判断は、新しい処理が必要である。既存の呼出・結果検査の枠と入力材料は再利用する。

自動判断は、完成順の確定字幕全体、音声、前後会話、利用可能なProspect・保持構造を参照する。通常表示の部分を含め、候補生成から漏れた山も見つけられる入力にする。Prospect・保持区間・字幕の意味まとまりを、そのまま同じ出来事の単位と決め付けない。演出判断に使う会話や出来事の参照は、確定済みの字幕区切りを置き換えない。

既存の音声抽出、[音量・音声区間の診断](../../evals/clip_composition/analyze_layer1_acoustic_upper_bound.py)、確定本文と音声の位置を照合する局所観測は利用候補。ただし、過去の診断閾値を演出判断へ流用する根拠はない。調べた実装範囲ではpitch測定の再利用先を確認できなかった。[局所音響観測の記録](caption-local-acoustic-observation-v001.md)にあるとおり、本文と音声の整列は正しい発声開始位置や発話の存在を保証しない。音響観測だけで演出を最終決定しない。

### 恒等デフォルトと抑制

[Step 2の指定解決](../../evals/clip_composition/presentation_effects_v001.mjs)には、無指定・空指定・全件通常表示で元の描画計画を返す先例がある。[既存テスト](../../evals/clip_composition/presentation_effects_v001.test.mjs)はStep 1の合成引数との一致も確認する構成だが、今回そのテストを実行していない。完成MP4全体のbyte一致まで実証済みとは主張しない。

将来の着工時には、変更禁止事項の一致と、同一環境での無指定時の描画結果を、短い回帰用素材等で確認する。壊れた指定、未知のID、判断未完了を黙ってnormalへ置き換えない。

同じ出来事かどうか、消してはいけない山かどうかは、物理的な抑制だけでは決められない。前段から出来事の参照と選択理由を渡し、後段で重複・競合を整理する。近接している別の反応を一律に間引かず、選択と抑制の経緯を調べられるようにする。技術QCだけで平坦さの解消を判定しない。

### 未解決事項と手戻りの注意点

- 短い反応や強い一語が長い表示字幕の一部に含まれる場合、既存単位では字幕全体が変化する。演出側から勝手に字幕を再分割したり、時刻を再推定したりしない。この制約下で価値が出るかは成立見本で確認する。
- 拡大等の見た目変更へ、現在の94pxでの表示検査合格を引き継がない。変更後の実画像を検査し、収まらない指定を黙ってnormalへ落とさない。
- 旧試作の演出名と今回の役割を結ぶ後方互換分岐は作らない。色・拡大の旧試作値も、そのまま採用できるとは扱わない。
- 字幕ごとに比較動画を再生成する旧QCは、[既存の完成裁定](digest-v1-phase2-completion-20260914.md)でproduction acceptanceから除外済み。将来の接続で再び有効にしない。
- 未使用素材2本程度は、落ち着いた素材と山・反応のある素材を対照的に確認する初期検証であり、広い素材への一般化の証明ではない。

## 妥当と判断された開発順

以下は、最終的なZEV側の実装範囲を確定し、別途着工指示を受けた後の順序。現在はどのPhaseも開始しない。

| 工程 | 最小の作業と確認 |
| --- | --- |
| Phase 1：字幕演出の配管 | 役割と表示字幕IDを固定し、小さな指定を共通描画へ接続する。恒等デフォルト、変更禁止事項、演出後の表示検査を確認する |
| Phase 2：一本の成立見本 | 保存済みの完成経路を使い、開発側が両役割を配置する。既存の通常版と、一本としての価値を確認する。個々の配置を人間に選択・承認させない |
| Phase 3：自動配置 | 見本の価値が確認できた場合だけ、全体文脈と音声から演出意図を選ぶ判断を追加する。Phase 2と同じ指定形式へ接続し、重複・競合と取りこぼしを診断できるようにする |
| Phase 4：未使用素材 | 調整結果を固定してから、落ち着いた素材と山・反応のある素材で確認する。人間は完成動画を見て問題区間だけを指摘する |
| Phase 5：観察による拡張 | 実動画の不足に応じて、役割を増やさない表現バリエーション、場面転換、章・時間表示を別々に検討する。種類を増やすこと自体を目的にしない |
