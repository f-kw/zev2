## 2. 全字幕から判断し、検証後に固定する処理

入力は完成時の通常計画にある全確定字幕と、既存Prospect・保持理由から得た文脈。場面切替と省略を明記し、隣接する字幕を無条件に同じ会話と見なさない。既存の演出判断や人間の正解ラベルは入力しない。

AIは全字幕を順序どおりに一件ずつ判断する。

| 判断 | 意味 |
| --- | --- |
| 通常 | この箇所へ追加で注意を向ける意味が薄い |
| Focus | 内容上の核を全文または一連続部分範囲で示す |
| 表現不能 | 意図は分かるが現行の連続範囲・表現では適切に示せない |
| 未解決 | 材料が足りない。必要な場合だけ音声・映像への具体的な問いを残す |

各回答には理由と根拠字幕を保存する。Vocal accentの役割も例外として記述できるが、未実装の表現をFocusに偽装して適用しない。文字の感嘆符だけから声の勢いを観測済みとしない。AIから任意色・サイズ・座標・animation・JSXを受け取らない。

実行時は、既存の「現在のCodexがJSON一行で回答する」接続を利用する。今回の実判断はCodexの担当agentが全入力を読み、意味を判断したもの。固定のキーワード規則、一定間隔、件数・割合のquota、手配置fixtureによる代用はない。人間の後修正として作った結果を自動案へ混ぜない。

固定前に次を検査する。

1. 通常計画から作った字幕本文・ID・順序と、全回答の件数・順序が一致する。
2. 理由の根拠字幕と文脈の参照が入力内に存在する。
3. 回答がその依頼の実byteに結び付いている。
4. 通常計画、文脈、判断prompt、保存した依頼・回答・結果の実byteが途中で変わっていない。
5. 部分範囲が原文の完全一致で、一意または出現番号付き、書記素を切らない。既存Phase 2の検証をそのまま使う。

回答漏れを通常へ補完しない。辞退、不正範囲、描画値混入、入力変更は固定前に拒否する。失敗時も依頼と生回答を残し、以前の試行を上書きしない。全Normalは形式上受け入れるが、意味判断の成功へ昇格させない。

固定後はPhase 1・2の読込・解決・本番描画へ渡す。通常計画へ色範囲だけを派生し、既存のNormal固定とResetへ接続できる。新しい描画stageや汎用編集Agentは作っていない。
