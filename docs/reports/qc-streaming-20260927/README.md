## 目的と処理単位

保存初稿326字幕・424検査点の全論理候補、RGB実byte、距離、等価クラス、唯一最小条件を保持する。
全編描画・字幕PNG生成・STT・AI・有料APIは実行しない。旧画像、旧証拠、14.8.1の共有証拠、初稿は上書き・削除しない。

現物では、完成フレームの一括抽出と字幕PNGの共通準備・平面色変換は既に実装済み。
RGBも一候補ずつ読むが、比較用合成は一検査点の全候補を一processで出力し、
比較画像と距離の再利用参照を全検査点の終了まで保持する。
終了時に全生成物を再読し、統合QCはその実行列と画像一覧を完全照合している。

今回の処理単位は一検査点。既存の合成命令を、物理生成候補32件ずつのバッチで実行する。
32は実行単位であり候補数上限ではない。論理候補順を維持し、同じ背景・矩形・順序付き描画層に限って物理生成を共有する。
実byteによる等価クラス照合と距離計算は既存処理を利用し、代表画像と距離再利用の寿命を一検査点内へ閉じる。

## 保管方式の監査案

1. 完成側RGB、全比較RGB、距離・クラス・判定を確定する。
2. 既存の共有証拠保存を使い、検査点の再生成条件・固定入力SHA・tool/code SHA・全候補・実行列・全生成物SHAを保存し再読する。
3. 正常で唯一最小の検査点だけ、今回の排他的出力directoryで作った比較RGBを再照合して整理する。
4. 不合格点は比較RGB一式を保持する。子process失敗・不完全出力・取消・保存失敗は未完了として残し、正常扱いしない。
5. 背景/完成フレーム、完成側RGB、共通準備済み描画層、元字幕PNGは保持する。整理後は不存在を明示し、実画像を読んだという記録へ置き換えない。
6. 独立再検証は保存記録・必須入力を照合し、未使用directoryへ再合成してRGB・距離・クラス・判定を再計算する。

新版の実行方式と参照の保持状態を明示する。旧方式は履歴の旧版検証として区別し、欠損時に旧版へfallbackしない。
