## 今回の観測経路

保存字幕・計画・元区間・過去音声観測を読み、完成MP4の音声を既存FFmpegでローカル復号する。

映像の意味理解や音を聴いた評価を追加したとは扱わない。

初回判断の担当には過去の人間回答と生成理由を渡さず、確定字幕と保存観測を渡す。
初回の実回答を保存してから、生成理由・許容集合・既知問題との関係を照合する。
取りまとめ担当は過去の指摘を知っているため、その後の候補整理を独立発見とは呼ばない。
