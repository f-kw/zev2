## 4. 自動選択の変更

既存の内容から許容集合を決め、再現可能に選ぶ処理を維持する。
意味役割 → 許容表現種類 → 具体表現を固定 → Panelの場合だけ許容背景を選択 → 最終presetを固定保存とする。
色とPanelの集合へ背景を別表現として横並び追加しない。背景を増やしただけでPanel全体の選択機会や他表現の割当を変えない。
無地・方眼紙・コミック枠の既存有限ID／資産だけを使い、AIから任意画像path・SVG・色・座標・倍率を受け取らない。

判断文へ背景候補と今回の人間方針を必要な範囲だけ説明する。内容上の理由があれば許容背景を絞れ、同程度なら再現可能に選ぶ。根拠のない文脈固定規則を作らない。
既存の可読性・安全域・字幕干渉検査を維持。映像未観測なら重要内容を隠さないと断言しない。適切な既存判断文を変更のためだけに変更しない。背景以外の役割・頻度・接続割当を一括調整しない。

表現種類と背景で選択の識別を分離。固定保存後の描画・再読・Resetで再抽選しない。固定意味判断と同じ許容集合では、背景追加後も非Panel字幕・接続の具体割当が不変であることを検査する。
新schema／規則版は明示する。旧回答のhashだけを変えて新回答と称さず、旧保存形式を通常入口で黙って変換しない。一件修正を自動背景選択と分離し、Resetは新固定自動案へ戻り、他overrideを変えない。
