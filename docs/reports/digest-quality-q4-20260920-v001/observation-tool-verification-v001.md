# Q4 短尺の数値観測補助：実装検証

## 結果

新規の観測補助と検査を追加し、小検査 **6/6** に合格した。実動画3本への適用は、描画完了後に親作業が実施する。本記録は実動画の観測完了や人間の品質承認を意味しない。

## 処理

- 固定された候補選定・描画入力・描画規則・完成記録・公開動画の参照を照合し、終了時に入力を再照合する。
- 各短尺を、対象字幕・前後字幕・字幕なし区間に隙間なく分ける。字幕なしという分類は、無音の判定ではない。
- 各区間を短尺30fps、Digest全体30fps、保存された元配信30fpsと実60fpsの偶数フレーム、実48kHz音声に対応付ける。保存16kHz観測への対応は有理数で残す。
- 共通の音声測定処理で短尺だけを2チャンネルのまま復号し、各区間のRMS・最大値・標本数を保存する。復号余剰は区間内集計から除外する。最終区間の直後標本は余剰の先頭になり得るため、その意味を明記する。
- 共通QCに保存済みの文字alpha外接矩形、背景を含む合成alpha外接矩形、板を除いた診断結果を照合して、文字と背景の位置関係を抽出する。保存公開PNGもSHAで照合する。

## 使用

```text
node tools/digest-quality/q4-observations.mjs <candidate-directory> <new-Q4-output-directory> <saved-original-clock.json>
```

今回の入力は `quality-q4-20260920-v001/candidates-v001`、時計は同配下の `c-all-input-v001/original-clock.json`。新しい管理対象出力ディレクトリを指定する。出力は `observation-record.json` と、候補ごとの生PCM・測定JSON。既存出力への書込みは拒否する。

## 検証と限界

検査対象は、全区間の時間対応、6フレーム字幕の48kHzステレオ測定、時計や前後字幕の不一致拒否、2行Panelの実測配置、PNGや板除去診断の不一致拒否、管理領域外出力の拒否。初回6/6後、独立監査で復号余剰の説明を限定し、直後標本の確認を追加して再度6/6。両回とも終了0、標準エラー0。

既存描画実装、Q3の44.1kHz入口、共通の音声測定処理は変更していない。今回の補助の実動画復号・画像閲覧・聴覚判断・新しい意味判断は0回。字幕の内容と見え方・聞こえ方の自然さ、元映像の重要部分への重なり、背景選択の良否は未判定。
