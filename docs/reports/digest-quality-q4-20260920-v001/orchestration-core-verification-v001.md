# Q4 自動背景選択・固定保存の実装検証

直接検査は **37 / 37 合格**、失敗0件、終了0、標準エラー0 byte。最終記録は [実行記録](orchestration-panel-tests-v004.json) と [TAP全文](orchestration-panel-tests-v004.tap)。前の3回は実装追加に応じた合格記録として保持し、失敗の上書きや試験値の変更はない。

## 変更した処理

- 意味から許された表現の種類を先に選び、Panelを選んだ場合だけ無地・方眼紙・コミック枠から背景を選ぶ。表現の選択に使う以前の識別は固定し、背景候補を増やしても非Panelの字幕と接続の割当を変えない。
- Panelの全許容背景を検査してから独立した識別で選び、最終的な有限presetを保存する。未知背景、任意pathや描画値、許容外・適用不能の背景、重複した回答key、背景を表現種類へ横並びにする回答を拒否する。
- 入力・回答・選択記録・再読証拠はv002。通常の新判断と、旧判断を明示的に再コンパイルした記録を来歴で区別する。通常入口で旧形式を黙って変換しない。
- 明示再コンパイルは旧選択記録・入力・回答の原文とハッシュ、旧意味判断と旧選択結果を照合する。今回の技術検査方針としてPanel背景だけ全3種を許し、非Panel・接続・既知の表現不能／未解決を保つ。旧原文と技術方針を新記録へ束縛し、再読時も再構成して照合する。
- 固定済み背景の再読、一件修正、Normal、Resetを検査した。Resetは新固定案へ戻し、他の保存系統を変えない。
- C-allでは通常接続を保つ方針を入力へ明示でき、通常接続以外を許す回答や入力表の書換えを拒否する。全体音声の保存済みASRは、音声候補の外にある区間も一意な観測IDで参照できる。

## 検証の限界

本記録は合成fixtureを用いた処理・保存・再読の直接検査である。新しい実映像の描画、視聴、新しい意味判断はこの担当では行っていない。HRB現物の明示再コンパイルとC-allの実入力・実判断・短尺描画は別の統合検証に属する。Q1未回答とQ3仮説を採用根拠にしていない。人間の品質合格を認定していない。

変更した3ファイルのbyte数・SHAと、各検査記録は [構造化記録](orchestration-core-verification-v001.json) に保存した。
