# Q4 短区間選定・Point Review経路の限定監査 v001

日付: 2026-09-20

## 結論

候補選定から標準Point Review作成までの経路を、Q4指示の第7・9・10節に照らして確認した。初回に指摘した保存済み入力との一致確認不足、および固定した描画実装との一致確認不足は、修正後の読み直しでともに閉鎖できる。

これは実行前のコード監査である。新しい意味判断の回答、候補画像、候補動画は閲覧していない。描画結果の技術合格や人間による品質合格を、この記録で認定しない。

## 選定と確認画面への接続

- C-allの325字幕すべてに対する固定案を使い、保存済み通常表示計画の行数・論理幅から短い1行、幅の広い1行、複数行の候補を選ぶ。同幅では元の表示順を使用し、同一字幕が複数条件に一致すれば一つにまとめる。
- 背景の種類を候補数の目標にせず、実際に自動選択された背景を記録する。条件に該当する字幕がなければ欠落として記録し、手で補わない。
- 前後の字幕は同じ保持区間の中に限る。通常表示の比較対象には、意味判断で通常表示が選ばれた字幕を使い、適用不能による通常表示への代替を混ぜない。
- 保存された自動案に手動変更がないこと、接続が通常カットであること、48 kHzの再生時計が保たれていることを候補選定前に確認する。
- 確認画面では、各動画の開始位置と字幕の対象位置から動画内の区間を導出する。標準Point Reviewの検証・未回答生成を使用し、別動画のハッシュや別のレビュー版を持つ回答を拒否する。
- Q1・Q3の既存レビュー定義は参照として保存するが、未回答を新しい確認項目へ転記しない。今回の対象外と、人間品質が未承認であることを保持する。

保存済み `candidate-tests-v001.tap` は4件合格、失敗0件。実行記録の終了コードは0、標準エラーは0 byteである。監査ではテストを再実行せず、現行コード・テスト・出力ファイルのSHA-256を再計算して保存記録と照合した。

テストで確認されているのは、保持区間を越えない前後文脈、背景数を強制しない選定、適用不能と意味上の通常表示の区別、条件不足の保持、重複候補の統合、同幅時の順序、手動変更・時計変更・接続変更の拒否、および描画実装・音声時計・元区間・映像検査状態・フレーム数が異なる完了記録の拒否である。

今回の保存済み入力と固定案内の入力全体が一致することについては、追加された直接照合を静的に確認した。保存ファイル一式を差し替える統合負例を、この4件のテストで実行したとは扱わない。
