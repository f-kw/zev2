## 人間判断を何へ反映したか

Panel機能の使用可、必要なら強く目立ってよいこと、文字の中央配置、色違いに留まらない背景の要求を、[本人原文との対応表](human-policy-reflection-v001.md)へ整理した。

内容から表現の許容候補を決め、具体的な表現を固定し、Panelが選ばれた場合だけ無地・方眼紙・コミック枠の背景を選ぶ。表現と背景の選択に別の識別を使うため、背景を増やしただけでPanelの選択機会や他の表現・接続の割当が変わらない。

背景は既存の有限な種類だけ。自由な画像path・SVG・座標・倍率や未知の背景を拒否し、選ばれなかった許容候補も適用条件を検査する。固定後の再読・描画・Resetでは再抽選しない。保存形式は新版を明示し、通常入口は旧保存形式を拒否する。
