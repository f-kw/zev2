# 候補を最終動画へ残す出力判断の実証 v001

対象：ZEV進行管理２ 指示-019（kawafmm承認済み）。2026-09-08。

既存のダイジェスト3候補を新しく比較し、覗かれる場面と逃走・捕縛の場面を残し、怖がらせ方の振り返りと総評を外す判断を得た。候補の件数や短縮量は目標にしていない。**採否の品質、必要な文脈が失われていないか、以前より良くなったかは人間未判定**である。

## 1. 候補群と新規判断

同じ保存済み素材の、実証済みダイジェスト候補3件を全件入力にした。候補群を追加・選別せず、3件の中で「出来事そのもの」と「その振り返り」の役割を比較した。過去の人間採否や最終使用状態は判断入力へ入れていない。

| 候補 | 判断 | 理由 |
|---|---|---|
| 覗かれる恐怖と抗議 | 採用 | 存在への疑いから発見、覗き方への拒否反応までがつながる独立した見どころ。 |
| 逃走の予想が外れ、捕まる | 採用 | 速度の確認、急加速への驚き、捕縛という独自の展開。最初の候補とは異なる出来事を示す。 |
| 怖がらせ方の振り返りと総評 | 不採用・弱い | 角度や時間差の分析には独自情報があるが、採用する出来事より追加の見どころが弱く、今回の構成を理解するための必須文脈とは判断しなかった。 |

最後の候補は完全な重複ではない。外すことで、怖がらせ方の解説と最後の評価が失われる。その損失を認めた上での採否であり、短くなったこと自体を改善の証拠にはしない。

| 記録項目 | 今回の結果 |
|---|---:|
| 全候補 | 3 |
| 採用 | 2 |
| 不採用 | 1 |
| 意味的重複として不採用 | 0 |
| 弱いとして不採用 | 1 |
| 文脈・全体構成上必須として採用 | 0 |
| 選択前の動画 | 4,831コマ・161.0333秒 |
| 選択後の動画 | 2,997コマ・99.90秒 |
| 外れた部分 | 1,834コマ・61.1333秒 |

二つの採用候補は「独立した見どころ」として残した。「必須」として残す能力や、意味的重複で候補を落とす能力まで実証したとは主張しない。これは一つの候補群で、追加価値の弱い振り返りを外す判断と実動画への反映を確認する限定実証である。

## 2. 判断と正式採用の分離

固定した制作要求は、保存済みの確定発話から内容上重要な箇所や見どころを選び、必要な文脈を残した短いダイジェストを作ること。候補群、元順の維持、使える既存Skill、共通製造への接続を固定し、採用候補IDや採用件数は記入していない。

新しい候補採否Skillへ渡すのは、制作要求、構造条件、候補の正式ID・題名・確定発話のIDと本文だけである。元動画の位置、尺、文字数の集計、過去の人間採用・不採用・使用済み情報を渡していない。既存の機械採用記録は探索結果と正式IDの対応を確認するためだけに読み、候補の内容は探索結果の全件から作り直した。

意味判断はこのCodexの実行中セッションが新規に行い、既存と同じ標準入力の受け渡しで保存した。固定fixtureの回答を返す実装や、本文の特定語に応じた採否分岐はない。推論APIは使っていない。候補採否は保存済み本文を根拠にした判断であり、新たに動画を解析したとは扱わない。

検査処理は全候補の回答網羅、正式IDの存在と素材所属、重複、元順、根拠の所属と順序、候補範囲、採用区間の非重複を決定的に検査する。意味が適切かはこの検査の対象外である。Skillの返答そのものを採用正本としては使わず、検査済みの不透明な証明を受けた昇格処理だけが、採用候補と不採用候補を確定する。

採用正本には、入力候補群、固定plan、新しい判断の要求・回答・結果、検査結果、元素材・書き起こしのSHAを束縛した。採用正本からのみ、候補内部の既存保持結果を選び、製造へ渡す編集区間を作る。

## 3. 既存の編集・字幕・製造の再利用

候補内部の保持判断はやり直さず、既存の意味判断と切り口の根拠を元本文・元音声対応に照らして再検査した。採用した2候補に属する4区間だけを元順で取り出し、元動画のコマ範囲と音声sample範囲をそのまま使った。旧planを再実行したり、旧planのSHA問題を修正したりしていない。

字幕表示区切りは既存Skillを使い、保持本文に対する表示単位を返した。正式時刻の解決、共通製造、Coreへの変換、rendererとstyleは既存実装を無変更で利用した。

新規の候補判断へ、review selector、指示-018の局所音響観測、字幕自動検出改善を混ぜていない。字幕の既知問題については、採否判断を保存した後に既存共通補修へ渡す。新しい字幕品質評価や新しい音響観測として数えない。

既存の人間指定を同じ元動画・元音声へ対応付け、次の3件を共通補修で再適用した。補修後の17字幕について、本文、元本文ID、表示の開始・終了コマ、字幕末尾、改行位置、styleが、残した区間の確認済み字幕と一致した。媒体、音声、採用区間、renderer、QC条件は変わっていない。

| 字幕 | 再適用した既知の補修 |
|---|---|
| え?いるんでしょ? | 採用動画内に発話がないという保存済み人間確認に従い、字幕を除外。 |
| なんかグロいやつに捕まってる | 開始を1,723コマ、終了は既存の1,794コマに保持。 |
| どこ? | 開始は既存の2,673コマに保持し、終了を2,708コマへ変更。 |

コマは30fpsで、終了はそのコマを含まない境界を示す。

採否判断は保存済み本文に基づくため、最初の候補の理由には、この除外字幕に対応する確認文も含まれている。したがって「疑いから発見」という説明が完成映像の発話として成立することまでは保証しない。採否の人間レビューでは、完成映像に残る拒否反応と抗議だけで独立した見どころとして妥当かも確認する。字幕の既知補修結果を、保存後の採否理由の書き換えには使っていない。

## 4. 除外候補と人間レビュー

比較画面では、外した振り返りを「角度の怖さ」18.87秒、「時間差の怖さ」27.30秒、「総評」14.97秒に分けて選べる。各区切りは選択前の字幕補修済み動画上の該当区間をそのまま再生し、終端で止まる。必要なら除外部分全体61.13秒も確認できる。

選択後は、残した二つの場面と、新しい終わり方10.80秒を選べる。最初から全編を見直すことを要求しない。人間が判断する点は、除外の妥当性、残した候補の弱さ、必要な文脈の欠落、見どころの維持、全体としての改善の5点である。画面の再生操作を人間合格に変換する処理はない。

## 5. 技術検証・保存結果

候補採否23検査、実入力との接続6検査、既存共通字幕補修47検査の計76件を確認した。未知・重複・欠落・逆順の候補、別候補の根拠、候補外の範囲、過去採否を追加した入力、採用件数の事前指定、検査済みでない結果の昇格、採用されていない候補の製造への混入を拒否する。採否理由の意味的な正しさを、これらの検査で合格にしてはいない。

strict型検査で見つけた追加処理の制御フローと型推論の診断を修正した。既存JavaScriptの型宣言がない4つの接続箇所は、実行時に検査する既存境界として明示している。修正後の診断135件は、今回の処理を除いた既存依存部分だけの検査と全文一致し、追加ファイルの診断は0件である。repository全体の型検査合格は主張しない。
