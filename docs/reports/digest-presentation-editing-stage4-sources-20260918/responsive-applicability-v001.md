## 操作と保存の意味

対象選択時は本文、時刻、現在の表現、保存状態を先に返す。選択した表現だけを別要求で検査し、未検査・検査中・適用可能・適用不能・検査失敗・古い観測を区別する。保存できるのは現在の対象・指定・保存版について適用可能と確認できた場合だけである。画面を経由しない保存にも同じ実書体・配置検査を適用する。

Colorの範囲、全文指定、表現、Pulseのピークを変えると、変更後の指定を検査する。Pulseは既存の表示時刻条件だけで候補を絞り、物理検査の失敗を「ピークなし」へ変換しない。対象を移動した後に届く回答、前の範囲・版に対する回答、要求した指定と異なる回答では、新しい対象の状態や保存可否を更新しない。「通常表示へ固定」と「自動案へ戻す」も同じ条件を満たすまで保存しない。

保存は短い状態読取り、ロック外での物理検査、保存直前の再照合、原子的な一件更新に分けた。検査中も状態取得・別対象取得・別の保存を進められる。保存直前には内容の版と両上書きファイルの世代を確認するため、他の変更が入り、その後元の内容へ戻った場合も古い検査による保存を拒否する。観測・入力・描画規則・PNGの実体も再照合する。長い実描画は保存ロック内で行わない。
