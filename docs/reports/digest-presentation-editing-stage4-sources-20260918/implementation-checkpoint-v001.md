# 工程IV — 実装checkpoint

この記録は実装固定のためのcheckpointであり、工程IVの完成承認ではない。工程IIIの受理済みSHA `4318d6bea024be793fca17d4333a3a42e6484874` を開始点とする。

## 実装した操作と処理

- 既存Vue画面の専用入口へ、動画、字幕・接続一覧、原文検索、表現・状態・変更の有無による絞込み、一件編集を追加。
- 字幕の有限表現、原文上で指定するColor、時刻で選ぶ既存の適格Pulse、接続の3表現、明示Normalと一件Resetを扱う。
- 同一PCだけで受ける操作用HTTP処理。登録した一つのDigestに限定し、任意path・commandは受け取らない。正確なHost・Origin・要求tokenの検査と、通常の文字描画・CSPで外部書込みや字幕文のscript化を防ぐ。
- 自動案2系統と判断根拠を固定し、人間の上書き2系統を独立保存。変更前の版を照合し、process間の書込みを直列化して一時fileから安全に置換する。
- 画面の未保存、保存済み、再生中、処理中の状態を区別する。再生中動画の時計から安定対象へ戻るため、接続変更後も旧動画の時刻を新しい計画へ誤適用しない。
- 対象の周辺だけを既存の描画・QCへ渡す。字幕の途中から始まる場合も全体での動作位相・fade・音響ピークを保持する。
- 背景と字幕画像は対応する元入力・投影・描画条件・実fileの一致を検査して再利用。同じ保存状態・範囲の完成動画も実体確認後に再利用する。
- 一対象の出力を一件ずつ実行。開始時の保存状態を独立固定し、途中の保存は実行入力を変えない。成功記録だけを媒体一覧へ登録し、失敗でも前の保存と動画を保持する。

工程IIIの無修正自動候補入口と、両上書きが空である検査は維持している。描画本体は共通であり、後修正版を無修正自動版として扱わない。

## 測定された制約

初回の短い周辺確認でも2分程度を要した。背景の範囲準備は約5.1秒で、字幕画像準備・合成・再描画照合・有限状態QCに約120.4秒を要している。同一結果の再利用は速いが、初回を即時確認と呼ばない。ブラウザー操作による体感時間も未計測。

処理の通常終了ではworkerのprocess groupへ停止を伝え、その子が終了することを小型検査で確認した。RemotionのChromiumは別groupであり、通常は既存の終了handlerが伝播する。Chromium起動直後からそのhandler登録前の窓については、停止後に孫processが残らないことを未検証。利用者のブラウザー全体を終了する処理は追加していない。
