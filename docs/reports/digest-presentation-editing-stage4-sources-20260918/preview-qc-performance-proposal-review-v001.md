## 変更内容

1. 元動画と完成動画を検査時点ごとに開き直す処理を、それぞれ一度の連続読込みへ変更する。必要な時点だけPNGへ書き出し、全編の全フレームをメモリへ展開しない。全体時計と範囲内時計の対応、出力枚数・欠落・余分な出力を検査する。
2. 同じPNGと既定4フレームの出入りで同じ透明度になる組合せを一度だけ計算する。既定の透明度と既存の色変換を保つ。重ね順が同じ途中までの合成を共有し、同一背景・同一区画・同一重ね順の完成参照だけを共有する。対象省略・別表現・他字幕・順序入替などの論理候補は全件残す。
3. 参照画像を一件ずつ読み、同じ完成画像と同じ参照画像の厳密な全RGB距離だけを共有する。SHAが一致しても実byteが一致することを確認してから共有する。閾値、重み、許容誤差は追加しない。
4. 品質証拠から一括抽出・透明度処理・参照生成を再導出し、実行順と全command引数、生成物、入力、全論理候補との対応を照合する。古い実行証拠を新方式へ変換する分岐は追加しない。
5. 入力照合、画像抽出、透明度準備、完成画像切出し、参照合成、厳密距離、証拠書出し、事後照合を計測する。既存の子process記録には実行時間と記録書出し時間を加え、配置検査・PNG描画・主合成の既存ラベル別合計を編集生成結果へ載せる。完了記録自身の書出しを測定済みとは称さない。
