## 目的と実装

完成Digestから気になる字幕・接続を探し、その一件を変更・保存し、周辺動画で確認して、複数変更をまとめて全編へ反映する操作を実装した。既存Vue画面へ専用入口を加え、同じPCの登録済みDigestだけを処理する。

字幕本文の検索、再生位置・字幕／接続一覧からの対象選択、表現・状態・変更の有無による絞込みを用意した。通常表示への演出追加、Colorの連続範囲、既存適格ピークによるPulse、接続の有限表現を扱う。「通常表示へ固定」と「自動案へ戻す」は別の保存操作である。

保存は描画と分離し、字幕と接続の上書きを別々に更新する。元の自動案と判断根拠は固定した。古い画面からの保存を拒否し、開始時の状態を描画用に独立固定する。出力中の新しい保存で、進行中の入力は変わらない。

再生中の動画が持つ時計から元の時刻・安定した対象へ戻す。挿入黒は所有する接続へ対応させる。字幕のない時刻を近くの字幕の変更として処理しない。画面上の未保存変更、保存済み内容、再生中動画、出力処理が使う内容を区別する。
