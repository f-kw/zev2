## 限定修正と元失敗の保持

1. 新判断のASR根拠IDが検証器の候補集合に入っていなかった。実際に入力したASR観測だけを既知根拠へ加え、未知ID拒否を維持。同じ生回答を再検証し、人が回答を修正していない。
2. 中間containerの丸めた時刻をAACへ渡すと終端packetが1sample短かった。PCM sample番号から時刻を作り直し、終端7,154,490とpacket連続性を確認した。合格済み全背景検証をSHA照合して再利用し、失敗した背景・AACを上書きしていない。
3. 字幕合成前のレイアウト検査がPCM背景をAAC期待値と比較していた。背景段階はPCM同士、完成段階は独立AACとのpacket一致を比較する配線へ修正した。失敗39件はすべて音声packet照合で、検査を無効化して通していない。

検査設営の修正・調整は5巡。macOSのtmp別名、試験用decoderの入力終端、描画ツールのローカルIPC、Soft重複検査へ渡す寸法の項目集合、公開後に移動したPNG参照へ対応した。最後の再実行前点検では、投影処理へ渡す参照の厳密な項目集合も照合した。IPCは通常の実行許可を受けて再実行し、拒否された操作を迂回していない。失敗現物は元の除外済みrunに保持し、[軽量参照](evidence/retained-failures.json)、[寸法の修正記録](evidence/soft-overlay-preflight-canvas-v002.json)、[物理検査の修正と再実行](evidence/physical-clock-proof-index-v001.json)から辿れる。
