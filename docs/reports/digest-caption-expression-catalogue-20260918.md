# 工程Iの字幕表現一覧

工程Iの実装用一覧。技術成立、人間の採用、自動判断の品質は別に記録する。Panel／Pulse／Bounce／Shakeの公開名は仮称である。工程Iの候補で使うこと自体を正式採用の根拠にしない。

当面の第一優先と工程順は[作業・引継ぎ記録](digest-caption-expression-stage1-20260918.md)、今回の範囲は[実装指示書](digest-caption-expression-stage1-sources-20260918/implementation-instructions-v001.md)を参照。

## 三方向の具体化

| 方向 | 工程Iの対応 | 既存との違い |
|---|---|---|
| 落ち着いて読ませる別外観 | 既存のPanelを再利用 | 文字の色・大きさだけでなく、全文を不透明な板でまとめる。重複した板部品は作らない |
| 出現時に一度弾む | Bounceを新規実装 | 字幕の表示開始から一度動く。表示中の音声ピークを基準にするPulseとは時間の基準が違う |
| 拡大以外の短い動き | Shakeを新規実装 | 大きさを変えず、短い左右移動の後に元の位置へ収まる |

三方向をこの三案で具体化した。色違いの量産、別書体の取得、任意動作の重ね合わせは追加していない。入力ごとの適用不能は、表現自体の見送りとは区別する。

## 新しい二表現の有限仕様

基準は30fpsの**字幕表示開始**。精密な発声開始を推定した値ではない。両表現とも既存の書体・塗り・縁・発光・改行を使い、保存済みの縦位置を維持する。Bounceは横中央を保ち、Shakeはその中央を基準に左右へ動いて元の位置へ戻る。AIは名前と全文指定だけを返し、px・座標・時刻・状態列を出力しない。

| 字幕内のframe区間 | Bounceの文字サイズ | Shakeの横移動 |
|---|---:|---:|
| 0〜1 | 88px | −12px |
| 2〜3 | 104px | ＋12px |
| 4〜5 | 112px | −8px |
| 6〜7 | 104px | ＋8px |
| 8〜9 | 96px（安定） | −4px |
| 10〜11 | 96px（安定） | ＋4px |
| 12以降 | 96px（安定） | 0px（安定） |

Bounceは8frame後、Shakeは12frame後に固定通常計画の状態へ戻る。完全に読める安定状態8frameと終了fade4frameが収まる最短期間を必要とする。既存の開始・終了fadeは各字幕に一回だけ掛ける。状態ごとには掛けない。表示終了、本文、改行を動きのために変えない。

新しい描画器は作らず、既存の字幕部品から各有限状態の原寸PNGを描き、既存の合成処理へ渡す。Shakeの移動はPNG内の実位置で表し、合成時の位置は共通のまま。配置がクランプされて所定の移動を失う場合は拒否する。

今回の32字幕は管理済み `line-seed-jp-extra-bold-v001` を使用。新しい書体・依存・外部素材は取得しない。Normalと新表現の安定状態は同じ固定通常計画を参照する。

## 入力ごとの適用可能性

実素材32字幕を既存の実フォント配置処理で測定した結果は、Panel 32、Scale／Pulseの幾何条件23、Bounce 26、Shake 29字幕。Pulseはこのほか実測頂点が表示期間へ収まる条件を個別に満たす必要がある。この件数は物理的な候補数であり、使用ノルマではない。

短い字幕と配置不成立は、それぞれの表現の適用不能としてAI判断入力へ渡す。一方だけ使えないときに、他方も自動的に使えないことにはしない。件数を増やすための縮小・再改行・時刻変更はしない。
