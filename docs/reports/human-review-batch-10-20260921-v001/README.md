一括入口の端末保存は元ページとは別の保存先を使う。画面内の明示的な入力・訂正は保存できる。回答ファイルの読み込みでは、未回答の行で既存回答を消さず、既存の原文と矛盾する回答の無言置換を拒否する。旧回答ファイルへは書き込まない。

チャット回答は番号から元ポイントを特定し、本人の実際の原文と受領日時を付けて保存する。自動キーワード分類、感想から採用への変換、別ポイントへの配布はない。明確な回答をフォームへ再入力させない。曖昧な回答は未確定の内容を保持し、無回答を「良い」へ補完しない。

受領後は新しい回答保存先に、一括回答、元5レビューごとの標準回答、集計、受領記録を保存できる。元レビュー自体のIDと対象版を保つ。実装、動画再生成、selector・override・原版・正式採用の変更はこの入口から行わない。
