## 成立した処理

候補の固定内容、二案それぞれの選択と出所、解決後の内容版、取得する媒体を分けた。小さなCLIから保存・再読・一件変更・媒体取得・取得記録の再検証を行う。人間レビューの回答を取り込む入口は設けていない。

共通原版の保持場面を一度走査して、省略の所属場面だけを分割し、追加の所属場面だけに直前区間を戻す。片方の編集済み出力をもう片方の原版にはしない。元字幕は開始・終了位置以外の全内容、改行、表示長、見た目を保持し、追加3字幕も既存の本文・出典・新IDを保持する。

保存では既存のプロセス間ロックを再利用する。現在の保存内容を読み直してから保存識別を照合し、一つの選択ファイルを同期書込み・renameで入れ替える。選択が元の内容へ戻っても新しい保存操作の識別は異なるため、古い画面からの上書きを拒否できる。別の履歴管理システムは作っていない。

一案の変更時は、その案の出所だけを更新する。他方の選択・出所と、両案の固定根拠は保持する。出力取得時は保存内容の写しを固定し、その写しから解決する。その後に現在の選択を取り消しても、以前の取得記録は当時の状態として再検証できる。
