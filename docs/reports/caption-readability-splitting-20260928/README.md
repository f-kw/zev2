## 分割・時計・演出保持

315→326は11表示の二分割と1表示の改行変更を手動境界回答へ固定した素材専用修復。
実幅／発話速度による自動分割はまだない。既存の本文全量・断片順序・外側時計検証を再利用する。

今回の保存本文は4,124文字単位atomからなる。各atomは元STT断片と元動画msを持ち、
既存timelineで接続前frameへ、その後接続後frameへ投影する。新しい文字数比例時計は作らない。
平均文字/秒は表示密度に留める。例えば000089末尾「ね」に4.442秒、000304の「ん」に7.043秒の
保存区間があり、実発話速度・休止・alignmentの滞留を平均値だけで判別できない。
音声による実話速確認は未実施。

一般化案は、親字幕を維持した分割計画へ実幅・既存語句境界・元断片時計・表示期間を渡すこと。
元開始／終了・本文連結・断片全量を固定し、内部境界だけ追加する。
部分Colorは対象語句を切らず、含む子字幕1件へ範囲を移す。
全文Color・Panel・Scale・motionは機械的な意味対象範囲を持たないが、今回全件1行・4〜13文字なので
まず未分割で保持し、動きを別の断片へ増殖しない。成立しない場合に無断で複製しない。

## 相談役へ提出する限定方針

候補はまだ本採用ではない。最初の局所候補を**通常144px、縁4px、外周4px、
縁／外周とも既存の名前付き色DarkSlateGray `#2F4F4F`**に絞る。
通常文字96→144pxで明確な差を作り、純黒の広い外周を残さない。現行白／黄／比較用水色で確認する。
追加の候補は最初の局所結果が成立しない場合だけ、指示の上限内に留める。

現行Bounce・Shake・Pulseは通常96px以外を拒否し、Scaleは絶対128pxへ置換する。
正常な96px入力の受理と、**文字サイズだけ144pxに変えたコピーの拒否を3種類とも実行して再現**した。
Pulseはこの素材に0件のため、合成した小型時計fixtureでのguard検査と区別した。
通常だけ144px、Scale128pxのままにすると「拡大」が逆に小さくなる。

推奨は、採用する通常sizeと旧96pxの正確な比から新しい有限stateを導き、
**時計・順序・往復の形・Shake移動量・フェードを変えず、サイズ束縛だけ新実行の版へ明示する**こと。
任意の重みや速度係数は追加しない。

- 144px候補ならBounceは132/144/150/156/162/168px、Pulseは144/156/168/180/192px、Scale192px。
- Shakeは144px、移動±12/8/4pxと既存frame割当てを維持。
- 旧保存物・旧版の定義/hashは書き換えない。未知の版を黙って受け入れない。
- 既存の余白／trustは完全一致検査を持つ。過剰余白の解消は新候補の実boundsで必要な最小保護幅を測って提示し、検査閾値の黙った緩和にしない。
- trust文中の人間再認定規則と、今回§23の「人間確認が明らかに不要なら相談役監査で採用可」の適用を明示してから新しい描画設定を採用する。

これは新しい動きの追加ではないが、既存の絶対サイズ契約には触れるため§26で先に判断を求める。
現時点では新しい有限state・registry・trust・rendererへの書込みは行っていない。
