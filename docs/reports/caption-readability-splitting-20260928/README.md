## 分割の処理と限界

315→326の旧修復は素材専用の11分割と1改行であり、その保存結果を出発点とした。
今回の処理は次のように分離した。

1. 元の本文・4,124文字原子・断片対応・元動画ms・接続後frameを保存入力から復元する。
2. 前後文脈を読んだ有限の意味境界判断を、本文とSHAに束縛した資料へ保存する。
3. 既存書体をloadしたChromiumで、候補区間の実幅と既存配置幅を測る。Motionは最大stateも確認する。
4. 本文全量・原子順序・外側時計を固定し、許可した内部境界だけで収まる表示単位を解く。
5. 2行例外は語句・時計・理由を明記したものだけ。理由のない自動改行や縮小はしない。
6. Color範囲は切らず、該当する子へ一度だけ移す。Panel/Scale/motionは時間分割・複製しない。
7. 保存後は入力と証拠から再計算し、結果を照合する。古い合格結果だけを再利用しない。

resolver内に素材ID分岐、文字数比例時計、話速係数、新APIはない。
意味境界の今回の有限資料はCodex2が判断したもので、AIの自動選択品質とは報告しない。
将来の通常経路へは既存の意味判断と接続する必要があり、今回の専用previewだけで製品接続完了とはしていない。
