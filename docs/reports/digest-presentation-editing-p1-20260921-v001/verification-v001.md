# P1：一件後修正の字幕画像生成 — 実装・性能検証

同じ画像・完成動画・品質検査を保ち、字幕画像を作るたびに繰り返していた準備を一件の処理内で共有した。**Panelは11.7%、Shakeは28.2%、適用検査の開始から周辺動画の取得完了まで短縮した。**

根拠は[本人の着工指示](instruction-received-v001.md)。開始点は `3168836bb255d989b18fc7fc440a6fdb68fc17f1`、branchは `codex/digest-presentation-editing-stage4`。数値・実装・実測・検査・保全の参照は[軽量検証記録](verification-v001.json)に結び付けた。これは技術提出用の結果であり、相談役による受理や人間品質の採用を代用しない。

## 何を変更したか

一件の適用検査と周辺描画に、処理の開始から終了まで所有する作画環境を明示して接続した。同じRemotion・コンポーネント・書体・Chromium・PNG設定を使い、準備したbundleを一回の処理内で共有する。通常画像と再現確認用画像は別々のブラウザーで実際に描き、各要求は新しいページと固定した入力を使う。画像cacheの識別・SHA条件は保持した。

両入口は同じ画像生成と既存の合成・QCを使う。固定された旧実行入口と既存の一枚完結アダプターは元のbyteを保持し、今回の対象以外へ共有寿命の責務を追加していない。版判定・入力変換・失敗時の旧方式への切替はない。

成功記録前・失敗・取消時には、その処理で取得した描画環境を回収する。起動途中の失敗も、取得した実子processの所有情報だけを使って回収する。既存PNGへの上書き、不完全画像の公開、前回成功画像の代用を拒否する。

- Panel: bundle準備 1.233秒、ブラウザー起動 0.381秒、新規画像作画 2.525秒、終了処理 0.031秒。
- Shake: bundle準備 1.012秒、ブラウザー起動 0.372秒、新規画像作画 15.812秒、終了処理 0.031秒。

字幕画像の準備＋新規作画は、Panelで11.765秒から4.138秒、Shakeで72.786秒から17.196秒へ短縮した。主動画合成・厳密再合成・有限状態QCは同じ処理を残しており、Shakeでは有限状態QCだけで約48.7秒かかる。完成媒体の再利用は約0.62秒で、今回その待ち時間の改善は主張しない。

同一マシン、Node20.19.6、Remotion4.0.481、同じChromium・素材・字幕・描画条件・権限条件・計測helperを使用した。画像・適用検査・完成媒体の保存先は各実行で未使用から始めた。既存のRemotion標準bundle cacheとOSの状態は両側同じ方針で保持しており、完全なコールド起動試験ではない。媒体取得までには2秒間隔の完了確認とHTTP全body受信を含む。

変更前一回、最終実装一回ずつの実測であり、時間保証や統計的benchmarkではない。接続範囲を絞る前の中間実装でも一回測定し、全一致と生の時間を保存している。最終実装を別領域へ再実行した値を報告し、最速値を選別していない。

## 一致・拒否・回収の検証

- 90出力すべてのPNG byteが旧新一致。同一byteの重複をまとめた23種類を全RGBAへ復号比較し、90出力との対応を保存した。この90出力にはcacheから再利用した16出力を含む。別途、22件のcache保存画像とその独立描画の証明も照合した。
- 2本の完成MP4はbyte一致。厳密再合成されたMP4とも一致し、元動画・音声・保持区間・時計・本文・動作状態・レイアウトを保った。
- 53検査点・1,727候補について、実RGBを再読して距離・同値分類・可視性・合否を再検算。全体／媒体内フレーム・期待状態・切出領域・重ね順・候補内容が一致した。完成側RGB 36,550,800 byte、参照RGB 1,193,371,200 byteを比較した。
- 小型では14枚を実描画。異なるPanel配色と通常字幕を挟むA→B→A、行マスク、中央校正、別系列での再現が全RGBA・PNG byte一致した。
- 共有描画とcacheの26検査、既存実行入口・観測・固定旧版の5検査、実画像1検査、書体・入力参照を取り違えた3拒否probe、既存の関連負例5検査に合格。skip・中間再実行は成功件数へ足していない。
- 起動失敗、描画失敗、取消、欠落・余分な画像・別出力・既存出力・入力変化・観測保存失敗を小型で確認。別jobと処理外の子processを保全した。最終実走後は観測された所有PIDだけを読み取り照会し、終了と一時領域の不在を独立確認した。

## 保全と残る事項

元10回答、修正後7ポイント未回答、Q3-2候補、Q4の入力不足、利用者の既存保存内容・登録元動画を保持し、参照byteを再照合した。本人による新しい動画採点は必要としない。新しい外部媒体送信・有料API・依存追加・契約／正式trust変更・main merge・tag・release・ショート着工は0。

検査設営ではTypeScript loader省略とsandbox内TSXのIPC制約を記録し、前者を正規loaderへ訂正、後者は通常権限審査後に実描画した。失敗記録・中間差分・中間測定を保持しており、旧証拠のSHAを新しい実装へ付け替えていない。

軽量記録から、管理済み出力先の旧新要求・PNG・MP4・全QC・処理観測・TAP・保全結果・独立レビューを辿れる。生成媒体や巨大な生の検査結果はGitへ追加せず、必要なsource・関連試験・比較helper・本報告をcheckpoint対象とする。

未回答の人間品質レビューと、既存の編集画面／Point Reviewのブラウザー制約はそのまま保持する。この性能検証を品質採用や工程IV全体の完成へ読み替えない。
