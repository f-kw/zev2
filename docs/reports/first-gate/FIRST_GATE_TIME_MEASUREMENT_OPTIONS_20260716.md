# 第一関門 時間条件の確定方法

作成日: 2026-07-16

状態: 提案のみ。人間承認前に再実施、素材取得、STT、LLM実走、実装を行わない。

## 測るもの

目標定義書v3に従い、上位5候補が人間へ提示された時点から、公開する3〜5本の候補確認、境界調整、必要な区間内カットと無音除去を終え、公開レベルの完成状態を保存するまでの1配信合計時間を測る。

STT、チャット流速選定、テーマ生成、ランキング、評価用fixture製造は時間条件へ含めない。候補単位時間の足し算ではなく、1配信の連続作業として測る。

「公開レベルの完成状態」が編集指示の保存を指すのか、動画書き出しまでを指すのかは、人間の定義確認後に開始・終了条件へ反映する。

## 案(a): 同素材で手直し工程だけ再計測

- 対象: 今回の上位5件を同じ順で再提示する。
- 計測: 上位5の確認から公開する3〜5本の仕上げ完了まで。
- 人間作業: 5判定、1セッション、計測上限15分。15分で終わらなければそこで未達として停止する。
- 機械作業: 既存素材と既存候補を再利用するため、新規STT・LLM実走なし。
- 利点: 最小コストで、手直し工程の計測方法と保存形式を確認できる。
- 限界: 候補、内容、操作箇所を人間が既に見ているため学習効果が入り、正式値にはできない。参考値と計測手順のdry-runに限る。

## 案(b): 初見素材2本目で最初から計測

- 対象: 改善に使っていない配信者・ジャンルから1配信を事前固定する。
- 計測: 固定済みパイプラインが出した上位5の初回表示から、公開する3〜5本の仕上げ完了まで。
- 人間作業: 素材選定1件・約1分を別セッションで行い、仕上げは5判定・1セッション・計測上限15分。合計見積り16分。
- 機械作業の参考原価: 現状は元配信STT 6時間32分 + STT後の正常な候補探索約1時間32分。評価用fixture製造は第一関門の時間測定には不要であり、同時に第二関門の再現率を測る場合だけ別作業として扱う。
- 利点: 候補既見の学習効果がなく、目標定義書の初見原則と15分条件を同時に測れる。
- 限界: 新しい素材1本分の機械処理が必要。15分を超えた場合も、その事実を正式値として残す。

## 推奨

**案(b)を推奨する。**

理由は、現在欠けているのが「初めて見る上位5を、本当に15分以内で3〜5本へ仕上げられるか」という一点だからである。案(a)は計測器と手順の確認には使えるが、候補既見による短縮を分離できず、第一関門の合否を確定できない。案(b)なら人間作業は16分見積りで30分警告ラインを下回り、1回の仕上げ判断も5件上限を守る。

承認を求める内容:

1. 案(b)を正式値取得の方法として採用するか。
2. 「仕上げ完了」の終点を、編集指示保存または動画書き出しのどちらにするか。

承認前の人間作業は0件・0分である。
