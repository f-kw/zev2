# 第一関門 時間条件の確定方法

作成日: 2026-07-16

状態: **案(b)を人間承認済み。正式初見素材の選定待ち。** 素材選定前に取得、STT、LLM実走を行わない。

## 測るもの

目標定義書v3.1に従い、上位5候補が人間へ初めて提示された時点から、公開する3〜5本の候補確認、境界調整、必要な区間内カットと無音除去を**編集指示として保存するまで**の1配信合計時間を測る。

STT、チャット流速選定、テーマ生成、ランキング、評価用fixture製造、動画書き出しは時間条件へ含めない。候補単位時間の足し算ではなく、1配信の連続作業として測る。

## 案(a): 同素材で手直し工程だけ再計測

- 対象: 今回の上位5件を同じ順で再提示する。
- 計測: 上位5の確認から公開する3〜5本の仕上げ完了まで。
- 人間作業: 5判定、1セッション、計測上限15分。15分で終わらなければそこで未達として停止する。
- 機械作業: 既存素材と既存候補を再利用するため、新規STT・LLM実走なし。
- 利点: 最小コストで、手直し工程の計測方法と保存形式を確認できる。
- 限界: 候補、内容、操作箇所を人間が既に見ているため学習効果が入り、正式値にはできない。参考値と計測手順のdry-runに限る。

## 案(b): 初見素材2本目で最初から計測

- 対象: 承認済み配信者リストのうち、開発素材と配信者・ジャンルの両方が重ならない1配信を事前固定する。機械側が題名、配信型、地力の事前予想を付けた2〜3本を提示し、人間が1本を選ぶ。
- 計測: 固定済みパイプラインが出した上位5の初回表示から、公開する3〜5本の編集指示保存まで。動画書き出しは含めない。
- 人間作業: 素材選定1件・約1分を別セッションで行い、仕上げは5判定・1セッション・計測上限15分。合計見積り16分。
- 機械作業の参考原価: 現状は元配信STT 6時間32分 + STT後の正常な候補探索約1時間32分。評価用fixture製造は第一関門の時間測定には不要であり、同時に第二関門の再現率を測る場合だけ別作業として扱う。
- 利点: 候補既見の学習効果がなく、目標定義書の初見原則と15分条件を同時に測れる。
- 限界: 新しい素材1本分の機械処理が必要。15分を超えた場合も、その事実を正式値として残す。

## 決定

**案(b)を正式値取得の方法として採用する。**

理由は、現在欠けているのが「改善に使っていない配信者・ジャンルの初めて見る上位5を、15分以内で3〜5本の編集指示へ仕上げられるか」という一点だからである。案(a)は候補既見による短縮を分離できない。案(b)なら正式初見性と時間条件を同時に測れ、人間作業も素材選定1件・約1分と、仕上げ5判定・上限15分の2セッションに分かれる。

承認済み条件:

1. 正式値は案(b)で取得する。
2. 仕上げ完了の終点は編集指示の保存とし、動画書き出しを含めない。
3. 候補素材は承認済みリスト内、かつ開発素材と配信者・ジャンルの両方が重ならないものに限る。
4. 素材選定後もランキング、プロンプト、モデル、窓分割、統合規則を変更しない。

次の人間作業は素材選定1件・約1分、1セッションである。選定後の仕上げ試験は5判定・上限15分、別セッションとする。
