## 先に検討してほしい反対論

### 1. 6分39秒は「10分程度」より短すぎないか

10分は最低尺や合否の閾値ではなく、実行部隊が50件を持ち込むような暴走を防ぐ規模目安として事前に定義された。4本で6分39秒は同じ規模であり、短いことだけを失敗にする規則はない。ただし、この解釈が目標の趣旨と矛盾すると考える場合は指摘してほしい。

### 2. 内部カット点を指定していないため「仕上げ」ではないのではないか

人間は外側境界と「無音・言い淀みを詰める」という編集方針を4件すべて保存した。内部カット点の一つずつの指定は実編集と同等の負担になり、人間資源の原則と衝突する。正式試験前のUIも編集種類の保存を完了条件としていた。一方、区間内編集を誰が具体化するかは後続工程の未解決課題である。この区別が第一関門の定義に照らして正当かを確認してほしい。

### 3. 初見1配信だけで十分か

第一関門は開発者本人が自分で使えるかを問う最初の関門であり、配信者をまたぐ安定性と他ユーザーでの維持は第二・第三関門に残す。初見原則は満たすが、1配信の偶然を第一関門でも許容できないと判断するなら、必要な追加条件を後知恵にならない形で示してほしい。
