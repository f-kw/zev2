# 正式初見・手直し試験UI設計

日付: 2026-07-16  
対象: `DmWu0jVQfTE` の候補上位5件  
状態: 実装前設計

## 1. 試験の目的

この画面の目的は候補を視聴することではない。初見の元配信から機械が選んだ上位5件を人間が確認し、公開候補3〜5本について、動画を書き出さずに実行可能な編集指示まで保存できるかを測る。

第一関門の時間条件は、上位5件が初めて表示されてから、5件の採否と公開候補の編集指示を保存するまで合計15分以内とする。

## 2. 人間作業量

- 1セッション5件
- 上限15分
- 人間へ依頼するのは、テーマ生成と順位付けが完了し、上位5件の媒体を機械検査した後だけ
- 動画書き出し、全候補確認、正解との照合は人間作業に含めない

## 3. 画面遷移

### 開始前

- 目的、完了条件、5件・15分上限を1画面で示す。
- 候補はまだ表示しない。
- 「正式試験を開始」を押した時に、1件目を表示して計測を開始する。これを「上位5件の初回表示」とする。

### 候補確認

1画面で1候補だけ扱う。常時表示するもの:

- 何件目か
- 経過時間と15分上限
- 題名と候補理由
- 画面内に収まる元配信動画
- AIが提案した区間
- 発話全文を使う境界選択
- 画面下の採否

次の候補へ移った時は、その候補のAI案を自動再生する。前へ戻って採否・境界・内部編集を変更できる。

### 完了

- 5件すべてに採否があることを必要条件とする。
- 公開候補は、外側境界と内部編集方針が保存されていることを必要条件とする。
- 公開候補が3件未満でも結果は保存できる。これはUIエラーではなく、第一関門の本数条件未達として記録する。
- 結果全文をコピーしてチャットへ貼れる。コピー後も前へ戻って修正できる。

## 4. 再生操作

意味が重なる名称を使わない。各ボタンには、再生内容・開始・終了・長さを表示する。

- `AI案を再生 00:00:00〜00:00:00（N分N秒）`
- `現在残す範囲を再生 00:00:00〜00:00:00（N分N秒）`
- 内部カットを追加した場合は、カット適用前後を区別して表示する

クリック時にどこまで再生されるかを画面内へ表示し、指定終点で停止する。動画は表示領域を超えず、縦横比を保持する。

## 5. 外側境界

- 時刻の直接入力や連続スライダーは使わない。
- STTの発話全文を表示し、その中の文字を押して開始・終了を決める。
- 孤立した1文字だけを選択肢として並べない。前後を含む意味の読める発話全文の中で選ぶ。
- 選択結果は既存の単語時刻へ変換する。人間は発話単語の途中を選ばないという合意を前提にする。
- 初期表示はAI案の前後30秒以上を含める。前後30秒を何度でも追加できる。
- 開始・終了はHH:MM:SS、選択した発話全文、ミリ秒を結果へ保存する。

## 6. 区間内編集

公開候補では、次のいずれかを必ず選ぶ。

1. 追加編集なし
2. 無音・言い淀みを詰める
3. 内部カットを追加する

内部カットは外側境界と同じ発話全文上で、削除開始と削除終了を選ぶ。複数追加・削除・修正できる。各カットはHH:MM:SS、選択した発話、ミリ秒を保存する。必要に応じて短い補足指示を入力できる。

画面が編集を実行する必要はない。第一関門で必要なのは、後工程が実行できる編集指示の保存までである。

## 7. 採否

画面下へ常時表示する。

- 公開候補
- 選ばない
- 別場面の文脈が必要

「公開候補」を先に押さなくても境界や内部編集を試せる。採否を変更しても、それまでの境界案は消さない。

## 8. 保存と取り消し

- サーバーへ自動保存しない。
- ブラウザ内の下書きだけを使う。
- すべての回答、境界、内部カットを後から取り消し・変更できる。
- 「この試験を最初からやり直す」は確認を挟み、誤操作で消さない。
- 最終結果はコピー可能な平文とJSONの両方を生成する。

## 9. 結果に残すもの

- 正式初見素材ID
- 固定された入力選定・テーマ生成・順位付けの生成系統
- 試験開始・終了・経過時間
- 各候補の順位、題名、採否
- 公開候補の開始・終了
- 内部カット、無音除去指示、補足
- 公開候補数
- 15分以内か
- 第一関門の機械判定材料。本数と時間の最終認定は人間が行う

## 10. 実装前検査

- 上位5件以外をUIへ混ぜない
- 正解・既存切り抜き・開発素材の人間ラベルを混ぜない
- 5件の元区間がすべて元配信時間内にある
- 発話テキストと単語時刻が選択範囲を覆う
- 動画のRange再生が開始・終了で止まる
- 戻る、採否変更、境界変更、内部カット削除、結果再生成ができる
- 次候補でAI案が自動再生される
- 時刻はすべてHH:MM:SSで表示される
- 画面は5件・1セッションで完結する
