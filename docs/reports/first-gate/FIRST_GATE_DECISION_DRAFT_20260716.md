## 判定案

**条件付き達成**を判定案とする。

根拠:

- 開発3素材では2/3素材が3本・15分以内を満たし、時間面は3素材すべて15分以内だったという人間提供集計がある。
- 初見1本では上位5中4件が公開候補で、候補の質と本数は関門水準へ到達した。
- 一方、関門合否に使う初見側の時間は未計測で、4/5は仕上げ可能性の見込み判定であり完成本数ではない。
- 改善に使っていない配信者・ジャンルという厳密な初見条件も満たしていない。

条件付き達成を正式達成へ変える条件:

1. 開発素材と配信者・ジャンルの両方が重ならない承認済み配信者の素材を事前固定する。
2. 初見素材で上位5から公開3〜5本の編集指示を保存する連続作業時間を測る。
3. 合計15分以内を実測する。動画書き出しは計測へ含めない。
4. 相談役レビュー後、kawafmmが最終認定する。

15分を超える、または公開完成が3本未満なら未達とする。結果後に時間範囲や本数条件を変更しない。

## 開発データと初見データの分離

開発3素材の値は、方式が関門水準へ近づいたことを示す補助証拠である。関門の最終合否は初見側だけで決め、開発側の良い値で初見側の欠落を補わない。

## 残る欠落

- 完成状態の保存物
- 改善に使っていない配信者・ジャンルでの初見値
- 相談役レビューと人間最終認定
