以下、人間レビュー結果です。原意を狭めたり、逆に一般化しすぎたりせず、対象機能へ正しく反映してください。

POINT 1\
違和感はありません。

ただし、これは何度も伝えている通り、Black Separatorと通常接続のどちらが優れているかを決める話ではありません。黒を入れた方がよい場面と、入れない方がよい場面があります。

差は人間でもほとんど比較判断できず、「なんとなくこちら」という程度です。これは優劣ではなくバリエーションと選択の問題です。

したがって、

- Normal CutもBlack Separatorも使う
- 人間へ微差のA/B比較を繰り返し要求しない
- どこで使うかはAI側の文脈判断・バリエーション選択として扱う

として下さい。

POINT 2\
Panel / 背景板という機能自体には違和感がありません。バリエーションとしてあった方がよく、効果的に使える機能だと思います。

ただし、現状は背景板に対して文字を綺麗にセンタリングできていないため、そこがかなり大きな違和感になっています。

**Panelではセンタリングを必須品質条件にしてください。**

もう一点、背景板のバリエーションを単なる「色違い」にするだけでは弱いです。

背景については、

- 色違い\
  ではなく
- 画像・テクスチャ・意匠そのものが違う背景

という種類のバリエーションが必要です。

なお、POINT 2に含まれていた**フェード自体は良かったです。**\
これはPanelの問題とは分けてください。フェード表現は採用してよいです。

POINT 3\
この動きの機能はとても良いです。残す方向で問題ありません。

気になったのは、**拡大縮小が荒く、カクカクして見えること**です。

機能を弱くしたり目立たなくしたりする必要はありません。問題は動きの滑らかさです。

どのpresetのどのスケール変化が原因かは実装側で特定してください。人間レビューではBounce / Shake / Pulse等を同じ短い区間で見ているため、私の発言を特定presetだけの問題だと勝手に決めないでください。

必要なら、

- 補間
- 中間状態数
- easing / motion curve
- frameごとの変化量

などを見直して、自然に滑らかにしてください。

POINT 4\
目立ちすぎる心配はありません。

必要な場面では、Panelが一番目立つ表現になっても構いません。「目立ちすぎないこと」をPanelの固定制約にしないでください。

ただし、問題はPOINT 2と同じです。

- 背景と字幕のセンタリング
- 色違いだけではない画像背景のバリエーション

は必要です。

---

今回のレビュー結果を記録するときは、

**採用判断**

- Normal Cut：使用可
- Black Separator：使用可
- POINT 2のフェード：使用可
- Panel：機能自体は使用可
- 動き系：機能自体は使用可、評価はかなり良い

**修正要求**

- Panelのセンタリング
- Panelの画像背景バリエーション
- 拡大縮小を含む動きの滑らかさ

を分けてください。

修正要求があるからといって、機能自体を「未採用」へ戻さないでください。

また、今回のレビュー運用から、Human Reviewのルールも追加してください。

**2〜3分級の動画を最初から最後まで集中して見せ、細かな違いや前後差を人間に判断させることを標準レビューにしないこと。**

人間は長時間の連続比較では注意・記憶・比較精度が落ちます。AIが時刻・状態・差分を保持できる部分まで、人間に丸ごと再確認させる方がレビュー品質を下げます。

今後は、

- 細かな演出・差分 → Point Review
- 全体のテンポ・単調さ・一本としての印象 → 必要な場合だけWhole Video Review

と分けてください。

「全部見せた方が安全」という設計にはしないでください。

さらに、今回のように一つのPOINTへ複数機能を混ぜる場合は注意してください。POINT 2はPanelとフェード、POINT 3は複数の動きが混ざっていました。人間の回答をreview\_idへ機械的に一括配布すると誤帰属します。

今後の比較HTMLでは、**一つの問いから何を採用・修正できるのかが明確になる粒度**にしてください。

比較HTMLの固定フォーマット化については、別途積んだTODOを維持してください。毎回違うHTMLや質問形式を作るのではなく、最終的には固定テンプレート＋review dataの形にします。

以上を記録・反映した上で、今回の修正要求を次の開発タスクとして整理してください。まだ実装していない修正を「反映済み」とは扱わないでください。
