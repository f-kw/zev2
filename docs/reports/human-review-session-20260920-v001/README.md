# 保存済み動画のポイント比較

Codexです。[ポイント比較HTMLを開く](/private/tmp/zev-stage4-editing-20260918/worktree/evals/clip_composition/outputs/presentation/stage4-editing-20260918-v001/human-review-20260920-v001/ポイント比較.html)。

**全編比較は不要です。** 見たいポイントのボタンを押すと、その区間だけ音声付きで再生して止まる構成です。比較欄は自動版、修正版の順に見ます。6区間を一回ずつ再生する長さは合計約27秒です。

| ポイント | 確認すること | 区間の長さ |
|---|---|---|
| 黒い接続 | 黒の長さ、前後のテンポ、音のつながり | 自動版3.9秒／修正版4.3秒 |
| 「逃げるやつ?」の背景板追加 | 読みやすさ、目立ち方、周囲から浮いていないこと。手前の黒へのフェードと戻りも含む | 各4.6秒 |
| 冒頭の字幕の動き | 弾む・揺れる・一瞬拡大する動きが声の反応に合い、読む邪魔にならないこと | 自動版5.7秒 |
| 自動で選ばれた背景板 | 「なんかグロいやつに捕まってる」の板が、読みやすさに役立ち、目立ちすぎないこと | 自動版3.3秒 |

「このまま使ってよい」「この箇所だけ気になる」「今回は判断しない」程度の返答を元の会話へまとめてください。理由・点数は不要です。「説明できない」「違いは分からないが両方使ってよい」も、そのまま記録します。

修正版は技術確認用の二変更を含む動画です。自動版より優れていることを前提にしません。今回見た箇所への判断として記録し、全編視聴済みや全体の使い分け・単調さの評価へ広げません。
