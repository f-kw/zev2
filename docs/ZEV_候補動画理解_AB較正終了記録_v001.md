### 3.2 Bで改善した範囲

- item 4では、追跡者が接近する非言語の出来事を説明し、文字だけでは未確認だった「何が起きたか」を補った。既存証拠の暗い通路での追跡・急接近に粗く対応する。これは叫びの前の状況観測であり、敵が加速する仕組みや因果判断を任せられる証拠ではない。
- item 2では、薬効の発言が本人の現在の状態や感想ではなく、画面内文書の一文の読み上げだと特定した。前段も同じ文書の朗読と分けた点は有用だった。
- item 3では、文字資料を読む場面という素材の性質を粗く捉えた。ただし静的で魅力が弱いという人間の映像適性判断まで正しく返したわけではない。
- item 3の導入・結末の選択にも改善はあったが、その文字情報はAにも存在した。Bで改善したことと、映像でしか確認できなかった情報であることを区別する。

今回、Bだけが無言の恐怖反応を正しく確認できた例はない。item 1では既知の無言反応をBも見落とした。item 4で有用だったのは、無言反応そのものではなく、叫びに先行する非言語のゲーム内出来事である。

### 3.3 Bで増えた誤認と、未確認の描写

- item 1では、必要な恐怖イベントを報告せず、別の画面上対象である砂嵐テレビの発見を後半原因に置いた。テレビが存在したこと自体を捏造と断定したのではなく、必要原因を取り違えた点が問題である。
- item 2では、文書の続きを本人の反応とするAの誤認を避けた一方、必要な文書後半まで不要としてしまった。両条件とも、既存証拠で必要とされた読後反応「バケモノ肯定派がいるん？」を不要扱いした。
- item 4では、実在する発話IDの本文「なん」を根拠に、逃走・回避を試みる発話への移行を説明した。その発話だけでは、説明する行動も自然な収束も支持できない。

肉塊・胎児状生物・挿絵の細部、メニュー静止画・立ち絵、足音の変化・カメラの揺れ、刺激がないという判断等は、既存人間証拠で確認できない部分を正解にも誤りにも加算していない。映像を見たというモデルの自己申告だけで真実と扱わない。

A/Bとも、離れた前後segmentを編集上の隣接だけから直接因果として結んだ誤認は今回確認されなかった。ただしitem 1の後半内部での原因の取り違え、item 5で回顧・話題背景と実際の出来事の原因を分け切れない問題は残った。回顧と識別できたことを、出来事本体の不足を診断できたことへ読み替えない。

## 4. なぜ共通後段として採用しないか

今回求めた共通後段は、出来事を粗く説明するだけでなく、原因、必要な前提、反応、自然な終わり、必要／不要な前後、映像適性を区別して、候補確認と区間化を簡略化する役割だった。

生成予算不足を解消した8192版でも、必要な恐怖映像の見落とし、文書と反応の混同、必要な内容の不要扱い、根拠のない終息説明が残った。部分的な状況説明の改善だけでは、一式を安定して任せる責務の成立を示せない。

また、技術上実在するIDを返せても、その本文が主張した観測を支えるとは限らない。task-037では全10回答の発話根拠90範囲と因果根拠21範囲、計111範囲について、IDの存在・所属・順序等を独立照合したが、意味的に不適切な根拠選択は別に残った。正式validator全体が合格したことにはしていない。

最初の契約拒否10件をtask-037で内容から分類すると、表現・schema上の細則を主とするもの5件、正式利用には危険だが内容比較に使える根拠・位置の不整合5件だった。本文の意味誤りを主因とする拒否0件、内容自体を評価不能にする拒否0件という分類は、回答全文の意味誤りが0件という意味ではない。未確認と非適用の符号化混同も併存している。

したがって、不採用理由を「10件すべて契約違反だったから」に縮めない。同時に、契約の表現規則を調整すれば意味理解まで成立すると結論しない。今回の不採用は、人間評価・既存必要内容と保存回答を意味的に比較した結果に基づく。

将来再開する場合の候補として残すのは、映像固有情報を補助観測として答える限定責務である。現在その運用・実装・正式skill採用を開始するものではない。

| 限定責務の候補 | 扱える範囲 | そこから昇格させない判断 |
| --- | --- | --- |
| 粗い非言語イベントの観測 | 追跡・接近等、映像で確認できる状況の説明 | 原因・因果の確定、反応強度や候補採否の決定 |
| 素材種別の観測 | 画面内文書を読む等、何を見て・読んでいる場面かの説明 | 必要文脈の選定、映像の魅力や最終適性の確定 |
| 映像状況の補助観測 | 文字情報だけでは不足する状況について、根拠と未確認点を分けた説明 | 正確な位置・カット境界、必要／不要区間の決定 |

- 原因・因果判断。
- 最低限必要な文脈（minimum context）。
- 自然な終わり（natural ending）。
- 必要／不要区間の判断。
- 正確なカット境界。
- 候補採否。

今回の記録は責務境界の結論であり、これらを別の新機能へ実装し直す指示ではない。main workflow、renderer、既存工程の責務や実装は変更しない。

## 6. IDと正式時刻の既存原則

LLMへ自由な数値時刻を生成させない。意味判断は既存IDへ結び、LLMは既存IDを返す。正式な時刻はZEV側が、正式発話artifactと既存mappingを用いた決定的処理で解決する。

- IDの存在・所属の技術検査と、そのIDが説明内容を支えるかという意味評価は別である。
- 発話IDから解決した時刻は発話の根拠位置であり、映像イベントの正確な開始・終了ではない。
- 無言イベント等に対応する発話IDがない場合、近隣発話を代用せず、内容が確認できても位置未確定として残す。今回の限定観測候補を理由に、新しい位置IDを作る契約や実装は追加しない。
- 部分収録の発話や既存mappingの未対応部分を、完全な音声・正確なイベント境界として補完しない。
- IDから正式時刻を決定できても、必要な場面の選定、自然な終わり、正式なカット境界の正しさを保証したことにはならない。
