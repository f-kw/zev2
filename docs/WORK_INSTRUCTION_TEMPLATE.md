## 4. 人間作業量の事前申告（必須）

- 人間に答えてほしいこと:
- 閲覧観点（そのまま公開可能か / 現在区間の編集で使えるか / 隣接尺を足して文脈を補えば使えるか / 別場面の文脈が見つかれば使える可能性があるか）:
- 現在区間の編集を問う場合に許可する編集（連続境界調整 / 区間内カット / 無音除去）:
- 隣接尺を足して文脈を補う場合、追加部分の必要情報と増える視聴コストをどう分けて確認するか:
- 別場面の文脈を問う場合、必要映像の存在は確認済みか未確認か:
- 「選ばない」が、そのまま公開しないだけか、区間内編集でも使えないか、文脈追加でも使えないか:
- 件数:
- 独立に答える問いの総判定数:
- 1セッションあたりの判定数（原則5件前後を上限、正解認定・関門判定はさらに必要最小限へ絞る）:
- 予定セッション数:
- 分割方法（日を分ける / 優先順で上位だけ依頼する）:
- 判定の重要度と、その件数まで絞った理由:
- 1件あたり推定時間:
- 合計推定時間:
- 時間計測の要否（既定は計測なし。必要な場合は人間の個別承認）:
- 使う確認形式（静止画・音声分離・選択式など）:
- ページ内に明記する「目的」「見なくてよいもの」「答えてほしいこと」「閲覧時に判断する観点」:
- 判定不能な問いがないこと:
- 候補価値監査の場合: 「公開したい / 悪くないが選ばない / つまらない / 文脈不明」の四択、文脈不明件数/監査対象総数を保存すること。手直し可能性の監査へ同じ選択肢を流用しないこと:
- 再確認の場合: 前回の媒体から意味上増えた情報（対応する別場面・追加信号・新証拠）と、同じ情報の再提示ではないこと:

判定数は、候補カード数ではなく、人間が独立に答える問いの数で数える。互いに排他的な状態から1つを選ぶ分類は1判定だが、採否・編集可否・文脈可否を独立に答えさせる場合はそれぞれを数える。開始・終了の選択など編集操作は判定数とは別に操作量として申告する。

人間作業がなければ、`0件・0分`と明記する。見積りは実行部隊が持ち込む量を抑えるためのもので、人間へタイマーを課したり、見積り超過を失敗にしたりしない。実時間は人間が計測を個別承認した場合だけ記録する。合計30分を超える見込みなら、着手前に警告し、件数削減・機械ふるい・問いの分割など負担を減らす代替案を併記する。総判定数が5件前後を超える場合は、1画面・1つの連続導線へ詰め込まず、日を分けるか優先順で上位だけを依頼する。1セッション終了後は機械側が結果を確認してから次のセッションを提案し、自動的に続行しない。
