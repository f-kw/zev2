# Production QCの責務とコスト

2026-09-14、kawafmmから送信された「Digest v1 Phase 2 — QC方針修正と完成動画確認」を正本として記録する。直前にChatGPTが作成し、kawafmmから送信されていない二つの指示案は採用しない。DECISIONS.mdへの追記は行わない。

## 原則

**製品の失敗モードは、それを直接確認できる最も低コストな層で検査する。**

下流の高コストなEnd-to-End試験で、上流ですでに確定できる事実を全件再証明しない。特に **N個の字幕 × 全timeline再符号化** のように、出力数に比例して長時間動画を再製造する検査をproduction QCへ安易に入れない。

そのような検査が必要なら、採用前に次の三点を明示する。

- 何の故障を検出するのか。
- 上流検査では検出できない理由。
- 全件実行が必要な理由。

説明できなければproduction必須gateにしない。代表確認の名目で新しい複雑なQCへ置き換えない。

## 字幕QCの責務

| 層 | 確認すること | 確認方法 |
| --- | --- | --- |
| 正式字幕データ | 原文完全保持、正式ID、順序、cue / line boundary、改行、行数、文字量、字幕時刻 | 正式source atomと境界・時刻データを全件照合し、既存の文字幅規則と上限を使う。文字量を調べるために動画を再符号化しない。 |
| 実フォント画像 | 実フォント描画、alpha bounds、safe area、行配置、clipping | 対象font/styleと結び付いた実画像の証拠を使う。成立済みで入力が変わらない証拠は再利用する。 |
| 完成MP4 | 字幕が最終動画へ反映されること | 代表1字幕の表示中央frameを1枚抽出して存在、欠け、位置を確認する。全字幕のE2E証明を完成条件にしない。 |
| 人間による視聴 | 字幕と音声の同期、読みやすさ、場面接続、文脈、テンポ、全体品質 | kawafmmが完成動画を視聴する。技術検査の合格から人間合格を推定しない。 |

完成MP4の通常検査は、実ファイル・非空・SHA、container、codec、画面寸法、fps、予定フレーム数と尺、音声stream、明らかなdecode / container errorを確認する。必要なら通常decode scanを一度行う。字幕ごとの別動画は作らない。

字幕同期は、字幕を除外した動画との差分検査では確認できない。保存済み時刻情報から、音響上の開始・終了を両方確定できなかった字幕、fallback使用字幕、Prospect接続境界に接する字幕を、不具合発見後の原因調査に使う `diagnostic-reference` として保持する。新しい音響解析や意味判断をこの確認へ混ぜない。

## 人間レビューと診断資料の分離

2026-09-14、kawafmmの「Phase 2 — 人間レビューUIを再作成する」に基づく追加方針。

> 機械検査・診断で得たリスク候補一覧を、そのまま人間の全件確認項目へ変換しない。

> 人間レビューは完成物を通常利用する形を基本とし、個別spot checkは代表例に限定する。

> 詳細診断情報は、不具合発見後の原因調査に使う。

今回の人間レビューは、完成したDigestを普通に視聴して、内容・テンポ・字幕・接続を確認する。通常画面へ詳細チェックリストや採点表を並べず、代表spot checkは最大3件とする。機械的に抽出した65件を人間の全件チェックリストへ変換した旧UIは採用せず、履歴として保持する。

fallback timing 54件、Prospect間の接続6件、内部接続5件は全件目視の要求ではない。診断資料は別fileへ保持し、通常画面では非表示にする。必要なときに開く領域も初期状態は閉じる。問題が見つかった時刻を記録し、その後に診断資料と照合する。

## Digest v1 Phase 2への適用と今回の誤り

325字幕を一件ずつ除外して長時間動画を再符号化する検査を完成条件に置いたことが誤りだった。文字量と画像配置は上流で確認でき、同期や全体品質はこの差分では確認できない。全件再製造が必要な未検出故障を示さないまま、製品の視聴へ進む経路を高コストな検査で塞いだ。

この方式は **production QCとして不要と判断して設計から外した**。今回の受入記録は `removed from production acceptance; not required` とする。旧検査に合格したとは扱わない。停止時の完了6件、未完了319件（7件目中断、未着手318件）、対象命令、process、終了方法は[停止報告](../reports/digest-v1-phase2-final-visibility-owner-stop-20260914.md)に保存済み。主合成MP4、画像、途中証拠、ログは保持する。

今回使用する証拠は、正式325字幕のsource照合、94pxの既存raster QC 325 / 325（違反0、字幕282の右端1834・安全上限1840、deterministic redraw）、完成MP4の字幕282一枚、通常MP4検査とする。新規325画像描画、再合成、動画再符号化は行わない。

技術確認が合格した時点の状態は `Phase 2 human-review candidate`。`humanQuality: not-evaluated`、`completionApproval: not-claimed` とし、次工程をkawafmmの実動画視聴とする。

## 残す検証用途

旧counterfactual方式の実装は削除せず、用途を **renderer regression / fixture verification** へ降格する。今後、完成動画ごとの全字幕に実行しない。rendererの完全性を調べる作業は別の小さいfixtureで行う。

Digest v1完成後に必要なら、fixtureによるregressionとして整理する。旧024 lossless方式等の最適化、renderer改修、QCアルゴリズム改修は今回行わない。
