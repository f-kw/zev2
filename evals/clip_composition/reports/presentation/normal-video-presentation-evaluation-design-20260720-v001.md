# 通常動画版 演出評価設計 v001

日付: 2026-07-20

状態: **人間承認済み。G1〜G3機械検査は実装・24/24合成テスト完了。G4〜G7は位置探索と5件の確認UI準備まで完了し、人間認定待ち。意味検出、LLM実走、比較動画生成は未承認。**

## 0. この設計が測るもの

本設計は、人間認定済みの`通常動画の演出文法 第2版 v001`（G1〜G7）に基づき、横長の通常動画へ付ける演出を次の3系統へ分けて評価する。

1. 出力契約を壊していないかを機械で検査する。
2. 意味判断が必要な場面を正しく見つけたかを、正解例と突き合わせる。
3. 最終的に見やすく楽しい動画になったかを、人間が少数のペア比較で判断する。

縦型ショートは別集計・別文法であり、通常動画の値へ混ぜない。**本設計は横長8本の文法に基づく初版で、ショート文法の蒸留後に共通部分と形式固有部分を見直す。**

評価の目的は、演出を多く付けることではない。必要な場所へ適切な候補を出し、不要または不確かな場所では付けないことまで含めて測る。

## 1. 評価単位と入力

### 1.1 入力

- 外側境界と採用発話群が確定した通常動画候補
- 発話・単語の時刻と文字列
- 話者情報（利用可能な場合）
- コメント、ナレーション、歌詞等の情報種別（既に判定できる場合）
- candidate-ranking / テーマ生成が記録した、候補の題名・理由・強い反応の説明
- 利用可能な既存画像・既存映像の一覧と出所
- 選択したstyleプリセット

切り抜き、expected、教師の演出観測は生成入力へ渡さず、採点時だけ使う。

### 1.2 出力の分離

意味判断の出力は、見た目の数値を直接作らず次の印だけを残す。

- どの発話・場面が対象か
- G4〜G7のどの意味マークか
- そう判断した1文の理由
- 根拠にした発話・素材参照
- `付ける / 付けない / 判断不能`

文字サイズ、位置、色、動き、背景板等はstyleプリセットと決定ルールが選ぶ。意味検出器が独自の係数や座標を生成しない。

## 2. G1〜G3: 機械検査

### G1 発話テロップ

機械で検査すること:

- 表示対象にした発話へテロップが存在する。
- テロップが元の発話・単語を参照しており、参照先が実在する。
- 元発話に無い内容を創作していない。
- テロップの順序が元発話の順序を逆転していない。

言い淀み等を削る場合は、元文字列との対応が削除として追跡できることを求める。言い換えや加筆はこの検査の合格に含めない。

### G2 読める意味単位への分割

現時点で機械検査できること:

- 単語の途中で分割していない。
- 分割後も全単語を順序通り参照している。
- 空の表示、参照の重複、未参照の脱落がない。
- 改行と表示切替を区別して記録している。

**「意味が読める単位か」そのものは、現在の66観測だけでは機械正解を作れない。** G2は第2版でも弱・保留で、直接観測は1動画だけである。ここを文字数の独自閾値で代用しない。初版では契約違反だけを機械検査し、意味上の読みやすさは第5節のペア比較で見る。将来、意味分割の人間正解が蓄積した場合だけ機械一致評価を追加する。

### G3 発話進行との同期

機械で検査すること:

- 表示の開始・終了が、参照した単語時刻から組み立てられている。
- 後の発話テロップが先の発話より先に表示されない。
- 同一話者の通常発話では、無根拠な重複表示がない。
- 複数話者の同時発話は、G6で明示した同時表示型だけ例外として区別されている。

許容ミリ秒を独自に置かない。開始・終了が参照語から決定的に再計算できるかを検査する。小気味よさや残し時間はstyleの比較対象であり、契約検査へ混ぜない。

## 3. G4〜G7: 意味検出評価

### 3.1 検出する対象

| 文法 | 検出対象 | 出力に必須の根拠 |
|---|---|---|
| G4 | 重要発話、間違いへの気づき、発見、強い感情 | 対象発話・場面と、何が強い反応なのか。既存の候補題名・理由にある「強い反応」判断を新規検出器より先に転用可能か確認する。 |
| G5 | コメント、ナレーション、歌詞等の情報種別 | 情報種別と、それが通常発話ではない根拠。 |
| G6 | 複数人が話す場面での発話者 | 発話と話者の対応。単独話者場面では発火させない。 |
| G7 | 話題人物、元ネタ、過去場面等の補足候補 | 参照先、利用可能素材、両者を対応付けた根拠。確信が無ければ`付けない`。 |

### 3.2 66観測を正解へ再利用できる範囲

人間正本8本・66観測は肯定例の台帳であり、網羅監査ではない。このため再利用範囲を次のように固定する。

| 文法 | 既存観測の使い道 | そのまま使えないもの | 準備判定 |
|---|---|---|---|
| G4 | E08の5動画を、強調候補の肯定例を探す索引として使える。E09は「文字やSEを必須にしない」抑制例の種になる。 | 多くが時刻未記録。人間メモに無い場面を非対象とは扱えない。 | **部分再利用**。元動画上の対象時刻を再特定し、人間認定した箇所だけ正解化する。 |
| G5 | E04の3動画に、コメント・ナレーション・歌詞の肯定例がある。 | 全情報種別を網羅しておらず、通常発話との境界時刻が揃っていない。 | **部分再利用**。対象区間と種別を再特定する。 |
| G6 | E05の3動画に、同時テロップまたは顔アイコンの肯定例がある。 | 単独話者場面を負例として監査していない。見た目はstyleで、話者対応の正解時刻も未整備。 | **部分再利用**。複数人場面と話者対応だけを正解化する。 |
| G7 | E10の4動画に、人物画像・既存映像・イメージ画像・小窓の肯定例がある。 | 参照素材の出所・利用可能性・対応確信が揃っていない例がある。 | **部分再利用**。参照先と利用可能素材の組を確認できた例だけ正解化する。 |

結論: 66観測は**正解候補の索引**として有効だが、現状のまま検出率を算出できる完成済み正解セットではない。観測本文から対象を再特定し、確認済みの肯定例・抑制例・判断不能を別ファイルへ置く。正本の66観測自体は変更しない。

### 3.3 採点

- 確認済み肯定例: `検出 / 未検出`
- 確認済み抑制例: `抑制維持 / 不要な発火`
- 判断不能または未ラベル場面: 採点対象外
- モデルが新たに出した未ラベル候補: 誤りとせず、要目視の発見として最大5件へ絞る

G4〜G7を合成点にしない。各文法ごとに、肯定例の検出数、未検出数、確認済み抑制例への不要発火数、形式不成立数を並べる。

## 4. 抑制・無演出の評価

演出を付けなかったことも出力として保存し、次を検査する。

1. 低確信なのに強い演出を付けていないか。
2. G7で対応素材が無い、または参照対応に確信が無いのに補足画像を付けていないか。
3. 映像だけで意味・感情が十分伝わる確認済み場面へ、文字やSEを必須追加していないか。
4. 単一動画だけの弱・保留演出をdefaultへ自動採用していないか。

`9dtwF5Exu5w` 00:15:49は、強い感情を顔アップだけで見せた既存の抑制例候補である。ただしこれは「完全な無演出」ではなく、「文字・SEを足さない選択」の例である。G4の全抑制正解を代表させない。

人間メモに無いことを無演出の証拠にしない。抑制評価は、人間が明示認定した場面だけを分母にする。

## 5. 総合品質: 人間ペア比較

### 5.1 目的

機械検査と意味検出が通っても、読みづらい、タイミングが悪い、うるさい、映像の良さを消す等の体感劣化は残る。これだけを人間が比較する。

### 5.2 比較単位

- 同じ入力区間
- 同じ発話群・外側境界
- 一度に動かすのは、演出候補の適用有無または1つのstyleプリセットだけ
- 比較媒体は`A / B`を匿名表示し、どちらが新案かを回答前に見せない
- 1セッション最大5件

回答は次の三択と任意メモだけにする。

- Aが良い
- 差はない
- Bが良い
- 任意メモ: 読みづらさ、タイミング、意味との不一致、付けすぎ、映像を邪魔した箇所

機械検査の合否やG4〜G7の検出数を同じ質問へ混ぜない。ペア比較は総合品質だけを判定する。

### 5.3 報告

勝敗だけでなく、`新案が良い / 差なし / 新案が悪い`を件数で並べる。合成点や独自係数は作らない。悪化が1件でも出た場合は、その場面が抑制規則で防げたかを個別に診断する。

## 6. 実装前に必要な正解整備

1. 66観測からG4〜G7の対象候補を抽出する。
2. 元動画上で対象時刻を再特定する。時刻を推測で補わない。
3. 同じ意味の重複観測を整理する。
4. `肯定例 / 抑制例 / 判断不能`へ分ける。
5. 最初の人間認定は優先度の高い5件以内とし、媒体付きで提示する。

正解整備と検出器の実装を同時に行わない。正解を見て出力規則を都合よく変えることを防ぐため、正解セットの版を先に凍結する。
