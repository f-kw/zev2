# 通常動画の演出文法 初回蒸留・人間判断反映 v002

日付: 2026-07-19

状態: **文法とstyleの境界を人間判断で確定。演出実装・LLM実走・比較動画生成・自動採点は未承認。**

この文書はv001の観測事実を変更せず、強調に関する分類と次の観察目的を更新する。

## 1. 確定文法

通常動画5本・41観測とkawafmmの判断により、次を同格の確定規則とする。

| ID | 文法として確定する処理 | 文法では決めないもの |
|---|---|---|
| G1 | 発話内容をテロップとして表示する。 | 書体・色・背景板の具体的な見た目 |
| G2 | 一度に見せる文字を、意味が読める短い単位へ分ける。 | 文字数の固定値、作品固有の分割テンポ |
| G3 | 発話の進行に合わせ、対応するテロップを切り替える。 | 切替時間の固定値、トランジションの種類 |
| G4 | 重要発話・間違いへの気づき・発見・強い感情の瞬間を、強調候補としてマークする。 | 強調の種類と使用頻度 |

G4は候補の検出で終了する。顔アップ、大文字テロップ、ズーム+SE、静止画、何も足さない等の選択は文法へ含めない。

## 2. styleへ移すもの

- 強調の種類
- 強調を使う頻度
- 1本の中での強調表現の統一
- どの強調候補を実際に採用するか

これらは製作者ごとのバリエーションであり、普遍規則を探さない。凍結中の演出実装方針にある`style`フィールド予約へ接続し、実装時はプリセットとして扱う。

### default案

「強調候補のうち特に強い少数にだけ適用し、少しだけ使って際立たせる」。

少数の件数・割合はまだ決めない。独自の係数、重み、頻度スコアを作らない。実装前にstyleプリセットとして別途承認を受ける。

## 3. v001からの変更

- v001の「強い感情に対して、文字強調・顔アップ・ズーム+SE・追加なしから文法が選ぶ」という案を撤回する。
- 文法はG4で強調候補を検出するまでとし、その後をstyleへ渡す。
- 強調の種類を比較して普遍的な勝者を決める評価は行わない。
- 既存5本の強調観測は削除せず、各styleで実際に使われた選択肢の実例として保持する。

## 4. 以後の通常動画観察

次の蒸留門は通常動画計8〜10本。目的は、現在1動画だけで観測した文脈カード、モノクロ回想、アイキャッチ、静止顔ズーム、全画面人物、イメージ映像、モノマネ対象の代役化等が別動画でも反復するかを確かめること。

強調の種類・頻度の使い分け規則は重点観測しない。強調について任意に記録するのは、G4の候補と思われる瞬間にプロが強調を使わなかった反例だけとする。
