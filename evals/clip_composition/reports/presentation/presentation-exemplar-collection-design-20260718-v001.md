# 演出のお手本採集 記録設計 v001

作成日: 2026-07-18

## 目的

実在の切り抜きで、どの出来事に対してどの演出が使われているかを少数の観察から外部化する。現段階では演出の良否を採点せず、実装・自動判定・重み付けも行わない。

採集が5〜10本に達した時点で、繰り返し現れた関係を「その条件を満たすか」というYES/NOの文法チェックリストへ蒸留し、演出評価の設計へ進む。層2（意味的間引き）の正解整備は、その副産物がどれだけ貯まったかを見てから再判断する。

## 正本と記入方法

- 正本: `../../outputs/presentation/exemplar-collection-v001/collection.md`
- 1本の切り抜きにつき、気づいた演出の発火点を1行ずつ記す。
- 時刻は切り抜き動画内の `HH:MM:SS`。フレーム単位の入力は求めない。
- 人間はMarkdownを直接編集しなくてもよい。会話へメモを返せば、実行部隊が正本へ転記する。
- 全演出を漏れなく数える作業にはしない。普段どおり観て、目についたものだけを残す。
- 「演出が一つもない」と判断した場合は、視聴済み欄に印を付け、発火点表へ `なし` と1行だけ記録する。

## 最小記録形式

| 項目 | 書く内容 |
|---|---|
| 発火時刻 | 演出が始まったおおよその切り抜き内時刻 |
| 種類 | ズーム / SE / テロップ強調 / 挿入画像 / 画面効果 / カット切替 / BGM / その他 |
| 発火の文脈 | 何が起きた瞬間に使われたか。例: 言い間違いに本人が気づいた瞬間 |
| 強度 | 弱 / 中 / 強。数値化・合成スコア化はしない |
| メモ | 重なった演出や、気になった点がある場合だけ |

強度の目安は次の三つだけとする。

- 弱: 内容を邪魔せず補助している。
- 中: 演出が明確に知覚できる。
- 強: 一時的に視線や注意の中心になる。

これは作品間の優劣ではなく、同じ演出を再現するときの大きさを区別するための記述である。

## 層2の副産物

話が飛んでいる、不要部分が抜かれている、離れた場面が接続されていると気づいた場合だけ、別表へ次を記す。

| 項目 | 書く内容 |
|---|---|
| つながり目の時刻 | 切り抜き内のおおよその位置 |
| 飛ぶ前 | 直前に何を話していたか |
| 飛んだ後 | 直後に何へ移ったか |
| 気づいた根拠 | 音、映像、話の飛び、テロップなど。分からなければ空欄でよい |

この欄は任意であり、演出メモを残す条件にはしない。採集段階では、意味的間引きか単なる無音詰めかを人間へ判定させない。

## 人間作業量

- 今回の必須作業: 0件。
- 今後の作業: 隙間時間に任意の1本を普段どおり視聴し、気づいた箇所だけメモする。
- 1本あたり数分という規模感だが、時間計測は求めない。
- これは正解認定や関門判定の監査ではないため、1セッション5件前後の監査上限は適用しない。疲れた時点で止めてよい。

## 次の門

視聴済みメモが5〜10本に達したら、実行部隊が次を行う。

1. 発火の文脈と演出の種類を、個別動画名を含めず抽象化する。
2. 「条件を満たすか」を人間が判定できるYES/NOの文法チェックリスト案を作る。
3. 観測数、例外、まだ判断できない型を分けて報告する。
4. 実装やモデル実走を始めず、演出評価設計の承認を人間へ求める。
5. 任意の内部間引きメモの蓄積量を報告し、層2正解整備を再開するか人間判断へ戻す。
