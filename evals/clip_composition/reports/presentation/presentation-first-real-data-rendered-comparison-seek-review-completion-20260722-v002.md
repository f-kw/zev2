## 2. v002で変えたこと

- A〜Dの各動画に「確認箇所1を2秒前から再生」「確認箇所2を2秒前から再生」を設置した。
- 押すと他の動画を止め、選んだ動画だけを対象位置の2秒前から再生する。
- 動画を切り替えた時は、停止した動画に残っていた「再生しています」の表示も消す。
- 「2秒後が確認位置」と画面上で明示する。
- 位置は動画ごとに異なる切断・接続結果から計算し、同じ秒数を4本へ使い回していない。
- 時刻入力、シークバー探索、全文再生、時間計測、サーバー保存は要求しない。
- 初期表示はA・Bだけを読み込み、C・Dは「決められない」を選んだ場合だけ読み込む。
- 画面が狭くても、2つの確認ボタンと回答欄が同時に見える配置にした。

## 4. 人間作業

通常経路は次の7操作・2判断。

1. Aの確認箇所1を再生
2. Bの確認箇所1を再生
3. Aの確認箇所2を再生
4. Bの確認箇所2を再生
5. 残す / 切る / 決められないを選ぶ
