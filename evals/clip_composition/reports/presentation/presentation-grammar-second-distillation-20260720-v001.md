- Gemini補助観測、無効v003、出現照合パイロットは蒸留根拠へ使わない。
- 人間メモに無い演出は不在でなく未確認とする。
- 文法とstyleの各項目へ、次の確度を付ける。
  - **強**: 複数動画・複数作風で確認
  - **中**: 複数動画・同系作風で確認
  - **弱・保留**: 単一動画のみ
- 反復は昇格の必要条件であって十分条件ではない。複数作風をまたいでも、作り手の選択肢に留めるべきものはstyleへ置く。

## 2. styleの選択肢集合

同じ場面に複数の良い表現が成立するため、一対一規則を作らない。各集合は「使える型」であり、動的な重み付け対象ではない。

セッション2のQ6で、この選択肢集合として扱う方針を認定済み。個々の見た目を普遍文法にはしない。

| ID | styleの選択肢集合 | 確度 | 観察から分かった範囲 |
|---|---|---|---|
| S1 | 発話の意味・言い方に合わせた文字造形 | **強** | 書体、色、傾き、振動、大きさ、吹き出し等が使われる。どれを選ぶかはプリセット。 |
| S2 | 強調候補の見せ方 | **強** | 大文字、ズーム+SE、顔アップ、静止ズーム、背景強調、何も足さない等が併存する。 |
| S3 | 情報種別・話者の表示型 | **強** | 通常テロップ、専用背景板、半透明板、同時テロップ、顔アイコン等がある。 |
| S4 | 参照先の補足型 | **強** | 人物画像、既存映像、全画面、小窓、イメージ画像がある。素材がなければ付けない。 |
| S5 | 過去場面の時間層表現 | **強** | モノクロ、ノスタルジック表現が併存する。 |
| S6 | 場面転換のアイキャッチ | **強** | 複数動画で観測。具体デザインと頻度はプリセット。 |
| S7 | 冒頭の専用導入・強い発話先出し | **中** | 同じ編集チャンネルの2本で反復。別作風での確認待ち。 |
| S8 | 場面限定BGM | **強** | 導入、終端、怖い話等で局所利用。曲の生成・選定はこの文法では扱わない。 |
| S9 | 目立たない移動・フェードによるテロップ出入り | **弱・保留** | 1動画だけ。defaultへ入れない。 |
| S10 | 感情・勢いに連動する背景 | **弱・保留** | 炎、黒、血、効果線は1動画だけ。style実例として保持。 |

強調の種類と頻度は、引き続き文法から除外する。`default`案の「特に強い少数だけ」は方向性に留め、件数・割合は決めない。

## 3. 発話単位より上の構成候補

セッション2のQ9で、発話単位の装飾とは分けた構成候補として保持することを認定済み。候補であり、全動画への必須適用ではない。

| ID | 構成候補 | 確度 | 扱い案 |
|---|---|---|---|
| C1 | 文脈を短いカードまたは小窓へ圧縮する | **強** | カード自体は1動画だが、小窓・出所表示を含む空間方向の情報圧縮は複数作風で反復。利用可能素材だけで組む候補。 |
| C2 | 利用可能な既存映像を、説明・回想・締めへ再利用する | **強** | 新規生成より先に既存素材を選べるか確認する。素材が無い場合は生成で埋めない。 |
| C3 | 本編と区別した短い終端を置く | **強** | 次回予告、ライブ映像、短いBGM付き終端が併存。終端を必須にはしない。 |
| C4 | 冒頭へ専用導入または先出しを置く | **中** | 同系作風2本だけ。通常動画の普遍構成にはまだしない。 |
| C5 | 音声と静止画・キャラクター素材から独自画面を再構成する | **弱・保留** | 品質上界の参考。現行ZEVの当面のAI対象外候補。 |

## 4. 抑制規則

セッション2のQ7で、低確信、対応素材なし、映像だけで十分な場合は、基本テロップまたは「付けない」へ戻す契約を認定済み。数値閾値は置かない。

| ID | 抑制規則案 | 根拠・確度 |
|---|---|---|
| R1 | 発火条件の確信が低い演出は付けない。 | 人間の既定方針。間違った前振りや参照素材は無演出より毒性が高い。 |
| R2 | 映像だけで感情が十分伝わる場合、強調候補でも文字・SEを足さない選択肢を残す。 | `9dtwF5Exu5w`のみ、**弱・保留**。 |
| R3 | 補足に使える既存素材が無い、または参照先の対応に確信が無い場合、画像・小窓を付けない。 | セッション1でG7と一体の契約として認定。 |
| R4 | 同じ動画内の見た目はstyleプリセットから選び、場面ごとに未発見の係数を増やして調律しない。 | 人間確定済みの型選択原則。 |
| R5 | 単一動画だけの演出をdefaultへ入れない。 | セッション1で認定。9本目以降またはショートで反復するまで弱・保留として保持。 |

## 5. AI対象境界

### 当面の対象候補: 既存映像への装飾

- 発話テロップ、意味単位分割、発話同期
- 情報種別・話者のマークと、プリセットによる表示
- G4強調候補へのプリセット演出
- 利用可能な既存画像・映像の選択、小窓、簡易文脈カード
- 既存映像の再利用、既存画面へのズーム・背景・SE・BGM候補

### 品質上界の参考・当面対象外候補: 画面の再構成

- 元配信映像を使わず、音声と静止画だけから全画面を作る
- キャラクターと背景素材を合成し、独自のキャラクターアニメーションを作る
- 外部素材や新規画像を創作して不足文脈を埋める

セッション2のQ8で、既存映像への装飾を当面の対象候補、画面の再構成を品質上界の参考・当面対象外とする境界を認定済み。再構成層の再開条件は、必要になった将来時点で別途定義し、今回独自に作らない。既存素材を選んで配置することと、新しい素材を創作することを混ぜない。
