## 2. 文法の形

演出を「場面Aなら効果Bを必ず付ける」という一対一表にはしない。同じ強い感情でも、大きな文字、顔アップ、ズーム+SE、テロップなし等が併存したため、次の順で扱う。

1. 場面についてYES/NOで確認できる事実を得る。
2. その事実に対して観測済みの**使える選択肢集合**を出す。
3. **付けない条件**を先に通す。
4. 残った選択肢を動画内の統一規則に合わせる。

どれを選ぶかの独自係数・重み付けは作らない。選択方法は今後の対照評価で決める。

## 4. 全体フォールバック

- 発火条件に確信がない場合は、読みやすい通常テロップと元映像だけに戻る。
- 間違った人物画像、前振り、過去映像、イメージ映像を付けるくらいなら付けない。
- 映像だけで意味と感情が十分に伝わる場合は、追加テロップ・SE・画像を抑制する。
- 同時に複数候補が成立しても、独自の点数で勝者を決めない。観測済みの組み合わせ（例: ズーム+SE）と、単独演出の対照を先に評価する。
- 動画内の基本書体、通常字幕の位置、背景板、色の統一範囲はプリセットとして管理する候補だが、具体値はまだ決めない。

## 7. 演出評価の設計案

初回評価では、実装範囲を広げず、複数教師で反復した次の3系統から各1〜2場面、合計最大5場面だけを使う。

1. 通常発話テロップの分割・同期
2. 画面外人物の画像または映像による補足
3. 強い感情に対する選択肢（文字強調 / 顔アップ / ズーム+SE / 追加なし）

比較は元映像+通常テロップを基準に、一度に一種類の演出だけを変える。人間の問いは次のYES/NOと三択に限定する。

- 発火条件は場面の事実と一致しているか。
- 意味が分かりやすくなったか。
- 映像の感情を邪魔していないか。
- 比較: 演出あり / 差なし / 演出なし。

形式検査は、文字の画面外はみ出し、字幕同士の重なり、素材参照切れ、映像と音の長さ不一致だけを機械で確認する。意味の総合判断は人間に残す。
