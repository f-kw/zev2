## 1. 目的と理論参照

B工程は、本体場面に対して「理解に必要な基準点・前振り・着地」を配信全体から探し、短尺の因果列として接続する意味圧縮工程である。

- **ZEV設計理論メモv1 (3)**: 遠距離接続は、フル視聴者が時間で積む文脈の最小代替であり、変化量を測る基準点を供給する。
- **同 (5)**: 変化量の大きさと面白さの符号は別である。配信者が谷を演目化したか、着地まで閉じたかの最終判定は当面人間へ残す。
- **同 (7)**: 出力原型は因果を再構成して一つの物語に閉じるミニドキュメンタリーである。単発切り出しはsegment 1件の退化形として包含する。

## 3. 事実: 現行でできること・できないこと

| 観点 | 現行で確認できたこと | 現行限界 |
|---|---|---|
| 意味timeline | 1件以上9,999件以下のsegmentを順序付きで持てる。segmentごとにsource IDと元時刻を持つ | segmentの物語上の役割（基準点・本体・着地）は持たない |
| source | ZEVG schemaは複数sourceを表現でき、最初に現れる順とsource列を一致させる | 現行ZEVO基礎映像v001はsourceを1件だけ受理する |
| 同一source内の複数区間 | 現行ZEVOは元時刻が昇順・非重複の複数segmentを連結できる | 元時刻を逆順へ並べ替えると不受理になる |
| 出力時刻 | segmentをframe単位で隙間なく連結し、字幕をsegment IDへ束縛できる | crossfade等で時間を重ねる表現は現行写像にない |
| 字幕 | 1 captionは1 segment内だけに閉じる | segmentをまたぐcaptionは拒否される |
| transition | DECISIONSでは基本を素繋ぎ、必要時のみ最小暗転・fadeとする | 意味情報パッケージへtransitionを入れず、現行ZEVO styleにも正式な接続選択契約はない |

既存接続実験は75 run中73 runが正解区間へ到達した一方、65/75が根拠範囲の完全な写しで、一致は0/75だった。旧callbackは全文168窓を完走したが、人間確認した2件はいずれも「関連はあるが原因ではない」で、意味評価0/2だった。これらは探索・時刻復元・複数区間比較の資産であって、B工程の意味問題が解けた証拠ではない。

## 4. 契約設計で閉じる必要がある論点

| 論点 | 決める内容 | 理由 |
|---|---|---|
| 物語順と元時刻順 | `ordinal`を完成物の物語順とし、元時刻は来歴として独立保持するか | 遠距離の基準点を本体より前へ置く等、source順と完成順が一致しない場合がある |
| segment役割 | 基準点・本体・着地等の役割を閉語彙化するか、理由文だけにするか | 理論(3)(7)を検査可能にしつつ、個別作品の型を先に固定しすぎないため |
| 変化量の根拠 | 本体との差、配信内位置、呼応した語・出来事をどの来歴で残すか | 人間作業を「採否」から「説明への納得確認」へ変えるため |
| 符号と対象外 | 谷の演目化、着地の閉包、現実の事件除外をどの段が所有するか | 理論(5)を単なる変化量ランキングと混同しないため |
| sourceの範囲 | 初版を同一配信・同一媒体に限定するか | 現行ZEVOが1 sourceだけを受理し、まず最小実証に閉じられるため |
| 区間順序変更 | 同一sourceの逆順・前後入替を初版から許すか | 現行ZEVO capabilityの非互換改訂が必要になるため |
| 接続余地 | hard cut用の厳密区間だけ渡すか、ZEVOが使える前後handleを別入力で渡すか | fadeや暗転のために意味区間を勝手に伸縮させないため |
| transition所有 | ZEVGは「場面が変わる」ことだけを伝え、見せ方はZEVO styleに限定するか | 意味/表現境界を保つため。時間差テロップは不要という裁定とも整合する |
| 音声と字幕の継ぎ目 | 語尾欠け、音声packet、caption segment閉包を何で検査するか | 素繋ぎでも境界品質が物語理解を壊し得るため |
| 時間写像 | hard cut、暗転挿入、crossfadeで元時刻→完成時刻をどう定義するか | 現行はsegmentの出力frameが連続し、重なりを表せないため |
| 失敗の帰属 | 探索不達、意味不成立、timeline不成立、ZEVO capability外を分離するか | LLMの品質不受理と出力系の能力不足を混同しないため |
| 人間確認 | 完成物1回の目視で、因果・転換・符号をまとめて確認するか | 確認回数を増やさない既存方針を守るため |

## 5. 推測: 最小のforward-only初版

現物から見る最小案は次である。これは推奨材料で、契約確定ではない。

1. 同一元配信・同一sourceだけを対象にする。
2. `segments`の配列順を完成物の物語順とし、各segmentは元時刻とsource atom来歴を保持する。
3. ZEVGは基準点・本体・着地の意味関係と選定理由を持ち、transitionの視覚・聴覚表現は持たない。
4. ZEVO v001はまずhard cutだけを決定的に実装し、必要な最小暗転・fadeはstyle側の次版候補にする。
5. 完成確認で、人間は「因果が伝わるか」「谷を娯楽として閉じたか」「場面転換が分かるか」を一度に見る。

この案でも、物語順を元時刻順から入れ替える場合は現行`presentation_output_base_media_v001`の能力外であり、ZEVO基礎映像の新versionが必要になる。

## 6. 素材固有の対症療法にしないための検査材料

- 遠距離はsource時刻差から決定的に記録できるが、「何分以上」を価値条件にしない。
- segmentの順序入替、同一sourceでの離れた区間、境界直前直後の発話、字幕のsegment跨ぎ拒否を合成fixtureで別々に発火させる。
- 処理結果は完成順、来歴は元source順で別々に照合する。
- transitionをZEVOへ置く場合、意味packageへpreset・fade時間・画面効果が漏れていないことを検査する。
- hard cutと将来fadeで同じ意味timelineを使えることを、表現差と意味不変の二層比較にする。
