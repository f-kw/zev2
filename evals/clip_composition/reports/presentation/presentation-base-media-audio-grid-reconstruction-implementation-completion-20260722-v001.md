## 3. 修正内容

### 3.1 変更した処理

従来は、連続復号した音声の時刻補正をFFmpegの暗黙動作へ任せていた。この方法では、先頭の312 sampleは補われる一方、直後にある48 sampleの内部空白が前詰めされていた。

修正後は次の順で処理する。

1. 音声を連続PCMとして一度だけ復号する。
2. 復号frameの時刻から、実音声が存在する範囲と存在しない範囲を決定する。
3. 実音声を末尾側から絶対sample位置へ移す。
4. 音声が存在しない全範囲を`0x00`の無音byteで明示的に埋める。
5. 移動前後の各実音声範囲がbyte単位で不変であること、全空白が無音であること、最終sample総数が正式時刻格子と完全一致することを検査する。

1msを許す、短い空白を無視する、最後へ不足分を足す、といった補正は入れていない。

### 3.2 回帰検査

全検査は**163/163件合格**した。

- 既存検査: **156/156件**
- 新規検査: **7/7件**

追加検査には、312 sampleの先頭空白と48 sampleの内部空白を持つ実Opus構造、音声総数の1 sample過不足、実音声byteの破損、空白への非無音混入、1 MiBを超える音声を複数回に分けて後方移動する構造を含む。既存のAAC系や正常な音声入力の検査は置き換えず、そのまま全件再実行した。
