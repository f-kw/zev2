## 2. 行折り規則の確定

初回動画では、短い本文まで必ず2行になる違和感を人間が見つけた。意味情報パッケージの字幕本文・発話時刻・意味まとまりを変えず、出力側の候補選択だけを次の順へ改訂した。

1. ページ数最少
2. 総行数最少
3. 最大行幅
4. 必要な改行内の幅の釣り合い
5. 決定的な境界順

この規則により、1行で物理的に収まる本文は改行せず、長すぎて1行へ収まらない本文だけを改行する。
