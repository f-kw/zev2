## 2. 停止条件

該当した停止条件は次の二つである。

- 設計に書かれていない設計判断・契約解釈が新たに必要。
- 契約・既存検査の矛盾を発見。

矛盾は次の四条項の組合せで生じる。

1. 設計§7.2は、内包するゲートA検査記録の組立処理へ、既存ゲートA検査器が返した`checkReport`を渡すと固定している。
2. 設計§4.1の許可importでは、package runnerがゲートAから直接使えるのは境界証拠生成処理だけである。既存ゲートA検査器の直接importは許可されていない。
3. package core内のB1検査器は、生のゲートA観測から既存検査器を呼べるが、公開返値はB1の検査名・合否・違反だけである。内側で得た`checkReport`をrunnerへ返す出口はない。
4. package coreのpublic export集合は完全固定されており、新しい純粋関数を実装者判断で追加できない。

したがってrunnerが§7.2の入力を作るには、次のいずれかを無断で行う必要がある。

- 許可されていないゲートA検査器をrunnerから直接importする。
- 固定済みのB1検査器返値へ項目を追加する。
- package coreへ未承認のpublic exportを追加する。
- 内包検査記録のbuilder入力契約を変更する。

いずれも承認済み契約の変更であるため、独自に選ばなかった。
