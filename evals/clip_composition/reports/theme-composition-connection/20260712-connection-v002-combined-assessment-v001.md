# connection-v002実走・境界分布 統合評価レポート

- 作成日: 2026-07-12
- 対象: connection-v001 / `llm-v012@gemini-web-flash` と connection-v002 / `llm-v013@gemini-web-flash`
- 素材: `nOEWCNc77MI_multiblock_material_v001`、`9dtwF5Exu5w_multiblock_material_v001`

## 1. 結論

connection-v002はテーマ根拠範囲の完全な写しを減らしたが、実績境界へ近づかなかった。挙動は変わったが境界精度は生まれていない。

したがって、`clip_composition_prompt_v013`は標準接続契約として採用しない。接続標準は`clip_composition_prompt_v012`とし、テーマ根拠範囲をそのまま区間として使う挙動を許容する。次の改善対象は下流の区間選択ではなく、上流が生成するテーマ根拠範囲の品質とする。

第二関門については、限定2素材の通し到達率だけが6割水準へ触れた。境界ずれは平均40〜52秒で、開始・終了の両方が±3秒以内に入った観測は0件のため、第二関門全体にはまだ触れていない。

## 2. 今回統合した2つの指示

### 指示A: connection-v002の設計・実走

- `candidateSpeechIds`を探索範囲からテーマ中心の照準へ変更。
- 照準の前後5分を文脈として渡し、モデル自身に開始・終了境界を判断させる。
- 接続入力とプロンプトを同一契約の両端として変更し、`clip_composition_prompt_v013`へ版上げ。
- モデル、対象25候補、各3 run、入力選定、文脈幅、採点器、成功基準、ID検査は固定。
- 撤退条件は実走前に登録。候補単位の多数決到達が25件未満へ落ち、一致が0のままなら棄却する。

### 指示B: 保存済み150 runの連続量再集計

- 追加LLM実走は行わない。
- v012の75 runとv013の75 runについて、開始・終了境界の実数値を保存。
- 符号付き平均・中央値、絶対ずれ平均・中央値、±3秒以内率、±5秒以内率を比較。
- 既存の一致±1000msは変更せず、別目盛りとして「関門水準=対象正解すべてへ到達し、両境界±3000ms以内」を挿入した四段階でも再集計。

## 3. connection-v002実走結果

| 指標 | v012 / connection-v001 | v013 / connection-v002 | 差 |
| --- | ---: | ---: | ---: |
| 一致run | 0 | 0 | 0 |
| 到達以上run | 73 | 74 | +1 |
| 不達・形式不成立 | 2 | 1 | -1 |
| 完全な根拠範囲の写し | 65 | 40 | -25 |
| 完全写しまたは片側境界継承 | 71 | 68 | -3 |
| 文脈内で別場面を選んだ事故 | 0 | 0 | 0 |

完全な写しは86.7%から53.3%へ減った。一方、根拠範囲の境界を少なくとも片側に使ったrunは94.7%から90.7%にしか減っていない。v013は片側を動かすことは増やしたが、根拠範囲への境界依存を解消していない。

候補単位の多数決では25/25候補が到達以上であり、事前登録した自動撤退条件には該当しなかった。ただし、この判定は到達維持を見る安全条件であり、境界精度の改善を意味しない。後段の連続量比較によって採否を確定した。

形式不成立はv013で1件。B素材候補32 run 1が`usedSpeechIds`を`400-25`と返し、範囲開始が終了を上回った。生回答は補正せず、ID検査によって不達へ分類した。

## 4. 境界ずれの連続量比較

符号付きずれは、負が実績より早い境界、正が実績より遅い境界を示す。率と絶対ずれは、形式成立かつ対象正解へ到達した観測だけを分母とする。

| 指標 | v012 / connection-v001 | v013 / connection-v002 |
| --- | ---: | ---: |
| 到達した候補×正解 | 79 | 83 |
| 開始境界 符号付き平均 / 中央値 | -37,057ms / -17,972ms | -47,651ms / -23,888ms |
| 開始境界 絶対ずれ平均 | 37,796ms | 48,316ms |
| 開始境界 ±3秒内 / ±5秒内 | 15.2% / 15.2% | 9.6% / 9.6% |
| 終了境界 符号付き平均 / 中央値 | +41,375ms / +26,190ms | +53,492ms / +48,427ms |
| 終了境界 絶対ずれ平均 | 42,722ms | 55,344ms |
| 終了境界 ±3秒内 / ±5秒内 | 8.9% / 15.2% | 6.0% / 9.6% |
| 全境界 絶対ずれ平均 | 40,259ms | 51,830ms |
| 全境界 絶対ずれ中央値 | 21,489ms | 33,234ms |
| 全境界 ±3秒内 | 19/158（12.0%） | 13/166（7.8%） |
| 全境界 ±5秒内 | 24/158（15.2%） | 16/166（9.6%） |
| 両境界とも±3秒内 | 0/79 | 0/83 |
| 両境界とも±5秒内 | 0/79 | 0/83 |

開始は早く、終了は遅い方向へずれている。つまり、テーマ根拠範囲を中心に必要区間を絞るのではなく、実績より広い区間を選ぶ傾向がある。v013では開始・終了の両側ともずれが拡大した。

同じ候補・run・正解に揃えた共通78観測でも、2境界の絶対ずれ合計はv013改善2件、同値41件、悪化35件だった。共通母集団の全境界絶対ずれ平均もv012 40,509msに対してv013 47,692msである。到達観測数の差だけが悪化原因ではない。

素材別にも、B素材は18,896msから25,425ms、別素材は60,058msから74,127msへ悪化した。特定素材だけの偏りではない。

## 5. 四段階の再集計

成功基準を事後に変更していない。既存の「一致=対象正解すべての両境界±1000ms」を維持し、その下に人間判断用の別目盛りとして関門水準±3000msを追加した。

| 段階 | v012 / connection-v001 | v013 / connection-v002 |
| --- | ---: | ---: |
| 一致（両境界±1000ms） | 0 | 0 |
| 関門水準（両境界±3000ms） | 0 | 0 |
| 到達 | 73 | 74 |
| 不達・形式不成立 | 2 | 1 |

一致0という厳しい二値基準だけが問題なのではない。±3秒の関門目盛りでも0件であり、±5秒まで広げても両境界が収まる観測は0件だった。今回の境界は「少し惜しい」分布ではない。

## 6. 第二関門の現在地

全正解は2素材合計38件。上流テーマ生成がhitした正解は27件で、現入力と上流結果における通し再現率の上限は71.1%だった。

| 系統 | run 1 | run 2 | run 3 |
| --- | ---: | ---: | ---: |
| v012 全38正解への通し到達 | 71.1% | 60.5% | 71.1% |
| v013 全38正解への通し到達 | 68.4% | 71.1% | 71.1% |

限定2素材では、再現率側は各runで第二関門の6割水準へ触れた。ただし、これは配信者単位のdev/test分割前の開発データであり、正式通過判定ではない。

境界側は、v012の絶対ずれ平均40.3秒、v013は51.8秒で、関門水準の±3秒から遠い。両境界とも±3秒へ入った観測も0件である。したがって、第二関門全体にはまだ触れていない。

## 7. 確定判断と次の投資先

1. v013は接続標準として棄却する。実験記録としては保持する。
2. 接続標準はv012+テーマ根拠範囲の写し許容へ戻す。
3. 下流へ独立した境界探索を要求する改善は、今回の2素材では精度を生まなかった。
4. 次の単変数実験は、入力選定・モデル・v012接続を固定し、上流のテーマ根拠範囲を実績境界へ近づける方法を対象にする。
5. 第二関門の正式測定前に、境界±3秒の集計単位を固定し、配信者単位のdev/test分割と初見データを導入する。
