# 境界のテキスト判断可能性 診断前設計

## 目的

boundary-v001で両境界±3秒に入ったB素材candidate 46 / expected 9が、「テキストだけで開始・終了を一意に選べる境界」だったかを検証する。同時に、2素材38 expectedCutsについて、単語境界が表現できるかではなく、テキストが正しい境界を判断する材料を持つかという第二の理論上界を推定する。

追加のLLM実走、Web Gemini実走、expectedCuts変更は行わない。

## 後知恵を防ぐ順序

1. 38正解・76境界について、boundary-v001の出力・成否を表示しないレビュー資料を作る。
2. 正解境界の前後テキストと機械特徴だけで、開始・終了を独立に分類する。
3. 76境界の分類を固定する。
4. 固定後にboundary-v001の保存済み結果を結合し、candidate 46と失敗群を対比する。

## 機械抽出する事実

- 正解境界直前・直後の単語と、句読点で区切った前後文脈。
- 正解境界とconnection-v001圧縮発話の最寄り開始・終了点との距離。
- 境界直前語の終了から直後語の開始までの空き。
- 直前・直後に文末記号があるか。
- 境界付近に、話題を切り替えることを明示する語句があるか。語句一致は候補証拠であり、自動合否にはしない。
- 開始境界では「新しい前提・出来事・発話の始まり」、終了境界では「文・反応・結論の完結」がテキストに現れているか。

距離・空き時間へ独自の合格閾値や重みを置かない。数値は比較材料としてそのまま並べる。

## 目視補助の二分類

各開始・終了境界を次のどちらかへ分類する。

- `text_judgable`: 音声・映像・切り抜きを見なくても、前後テキストからその単語境界が隣接候補より明確に選べる。明示的な開始句、話題転換、文やオチの完結など、選択理由をテキストだけで説明できる。
- `audio_visual_cue_likely_needed`: テキストが意味的に連続している、近傍に同程度に妥当な境界が複数ある、または間・笑い・声色・表情・映像反応を見ないと実績位置を一意に選べないと推定する。

各判定に1文の根拠と、`clear` / `ambiguous`の確信度を残す。二分類自体は必ず確定し、`ambiguous`を楽観側へ自動加算しない。

## 判断材料上界の集計

- 境界単位: `text_judgable` / 76。
- 開始・終了別の内訳。
- 正解区間単位: 開始・終了が両方とも`text_judgable`のexpectedCuts / 38。これをテキスト入力の判断材料上界・第二版の主値とする。
- 片側だけテキスト判断可能な正解も別記する。
- 素材別の内訳を出す。

これは2素材の開発データ上の診断上界であり、初見データへ一般化した能力値ではない。

## 成功要因の仮説

分類固定後、次を検証する。

1. candidate 46 / expected 9の開始と終了がともに`text_judgable`なら、「±3秒成功はテキストで分かる境界だった」という仮説を支持する。
2. 第二素材の改善0または±3秒0の正解で`audio_visual_cue_likely_needed`が多ければ、素材差の一因として判断材料不足を支持する。
3. 第二素材にも`text_judgable`が多いのに±3秒0なら、主因は判断材料不足ではなくboundary-v001の選択能力・指示・探索に残る。
4. candidate 46が`audio_visual_cue_likely_needed`なら、成功はテキスト合図仮説では説明できず、偶然または別信号として扱う。

## 戦略比較

診断後、次の3案を同じ表で比較する。

- 非発話シグナルを追加して境界精度を追う。
- 境界は現在の約±20秒水準を人間の手直し領分として仕様化し、再現率側へ投資する。
- テキスト判断可能と判定できる境界だけ三段構造を適用し、それ以外は人間へ返すハイブリッド。

工数は、実装・データ準備・評価追加・人間確認を分けた作業項目として見積もる。根拠のない時間係数や重み付き総合点は作らない。
