# input-selection-v004 別素材検証結果

## 結論

固定した「チャット流速上位100分」は、別素材でも正解25件中18件をモデル入力に入れた。B素材の12/13より低く、同水準の入力可視性は再現しなかったが、正解の過半数を拾う効果は初見の別素材でも確認できた。

モデルは入力で見えた18件のうち15件を拾った。残る内訳は、入力選定で見えなかった7件と、入力には入ったがモデルが拾わなかった3件である。結果を見た後にNは変更せず、この生の結果を採用判断へ返す。

## 失敗の分離

- 入力選定の失敗: expected 1、2、3、4、5、19、21の7件。チャット流速上位100分の外だった。
- モデルの失敗: expected 17、18、22（素材block 20、21、27）の3件。入力には入ったが候補根拠が重ならなかった。
- 人間が除外したblock 8、16、19、22、23、30は分母にもhitにも入れていない。4候補が除外区間へ重なった事実だけを監査欄へ残した。

## 参考計算

事前登録した配信長比と上位割合は、対象配信がB素材とほぼ同じ長さだったため、どちらも上位100分になった。入力内は正式結果と同じ18/25で、参考条件のLLM追加実走は行っていない。

机上の可視性は、上位50分で9/25、正式な上位100分で18/25、上位150分で21/25だった。これは診断値であり、採点後に閾値を動かす根拠には使わない。
