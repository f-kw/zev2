# input-selection-v004 別素材検証 事前登録

## 目的

B素材では、チャット流速上位100分を入力にすると正解13件中12件が入力内に入り、LLMもその12件を拾った。ただし100という閾値はB素材の正解を見て選んでいる。

今回測るのは、正解位置を見ずに選ぶ別素材でも固定N=100が機能するかである。採点後に都合のよい閾値へ動かさない。

## 正式判定

- 入力選定は `input-selection-v004`、チャット流速上位100分で固定する。
- 1分ごとのコメント数を対象配信内の平均で割り、相対順位だけを使う。絶対コメント数は選定に使わない。
- 同順位なら配信時刻が早い区間を先にする。
- LLM実走はN=100で1回だけ行う。
- プロンプト、実モデル、窓分割、機械統合、採点器はB素材v004から変えない。

## 参考計算

同じチャットログから次の入力可視性を機械計算する。参考値ではLLMを実走しない。

1. 配信長比: B素材の「100分 / 11,824,121ms」を対象配信へそのまま移し、選択する完全1分区間数を `floor(対象配信長ms × 100 / 11,824,121)` とする。
2. 上位割合: B素材の「100 / 完全1分区間197個」を対象配信へそのまま移し、`floor(対象の完全1分区間数 × 100 / 197)` 個を選ぶ。

端数は切り捨てる。これは選択時間または上位割合をB素材以下に保ち、結果を見た後の切り上げを防ぐための固定規則である。

## 素材条件

- B素材とは別のVtuberゲーム配信。雑談、発表、歌、イベント主体は除外する。
- 承認済み素材プールのうち、B素材と同じホロライブから先に選ぶ。
- 適格候補の中でB素材との配信時間の絶対差が最小のものを選ぶ。独自の「同程度」許容幅は置かない。
- チャットリプレイを取得でき、配信末尾までJSON解析できること。
- 実績ある切り抜きから、ローカルSTT、大域照合、人間確認、固定テーマを経て新規fixtureを凍結できること。
- 対象固定前に、expected時刻、チャット流速集計、候補テーマ、過去の範囲hit結果を見ない。

2026-07-12の候補調査で既存fixtureの正解件数と時刻を確認した。このため既存fixtureは今回の汎化対象に使わず、新しい配信・切り抜きの組を選ぶ。

## 素材の決め方

1. Marine Ch. 宝鐘マリンの公開済みゲーム配信をメタデータだけで列挙する。
2. B素材自身と既存fixtureの元配信を除外し、B素材との時間差が小さい順に並べる。
3. 順番にチャットリプレイ有無と実績切り抜きの有無だけを確認する。
4. 両方を満たす最初の配信を対象として固定する。
5. チャット取得不能またはfixture製造不能なら理由を残して次順位へ進む。正解位置や採点結果を理由に差し替えない。

## 採点後の読み方

- N=100で入力外になった正解は入力選定の失敗。
- N=100で入力内なのに拾えなかった正解はモデルの失敗。
- 配信長比・上位割合で入力内になるかは、固定100分が配信長に対して短すぎたかを見る診断材料。
- 入力内、入力外、全正解、候補数、根拠範囲カバー率、候補あたりhit、失敗分類をそのまま報告し、合成点は作らない。
- 1素材の結果だけでNや割合を再調整しない。
