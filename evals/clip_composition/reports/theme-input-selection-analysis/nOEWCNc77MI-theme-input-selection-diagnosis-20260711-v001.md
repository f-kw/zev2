# B素材 theme-v002 入力選定診断 2026-07-11 v001

## 結論

発話量上位50が正解13件中12件を入力外にした主因は、正解区間の発話量順位が配信全体へ広く散っていたこと。正解の最良順位は `1, 69, 75, 79, 83, 85, 110, 129, 238, 252, 257, 334, 367位` で、上位50に入ったのは1件だけだった。

入力内だった1件も、正解5.241秒のうちモデル入力に入ったのは末尾660msだけだった。v002の最寄り候補は正解終了の4.682秒後から始まっており、遠い別場面を選んだのではなく、同じ30秒チャンク内で正解直後を選んで外している。

v003実験ではプロンプトを変更しない。変更するのは入力選定だけとし、発話量上位50から、同じローカルSTTの元配信全文を既存の窓分割へ渡す方式へ変える。

## 前提と測定方法

- 発話量ランクは、実際に上位50を作った処理をそのまま再現した。
- 母集団は元配信を30秒固定幅で分けた394チャンク。
- 指標はYouTube粗字幕の非発話表記を除いた発話文字数。重み付けや合成スコアはない。
- 同点は元配信時刻が早いチャンクを上位にする。
- 粗字幕segmentが30秒境界をまたぐ場合は、元処理と同じく全文字数を両方のチャンクへ計上する。
- 正解が複数チャンクをまたぐ場合は全チャンクを記録し、その中の最上位を代表順位として併記する。
- 無音について音声判定はしていない。以下の「STT空白」はローカルSTTに語が記録されなかった時間であり、音響上の無音とは断定しない。

## (d) v003設計案 — 入力選定だけを変更
