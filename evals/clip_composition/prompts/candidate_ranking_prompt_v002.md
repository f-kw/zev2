# candidate-ranking-v002

あなたは、配信から生成済みの切り抜きテーマ候補を、人間が最初に確認する価値が高い順へ並べます。

入力には候補ID、題名、候補にした理由だけがあります。入力にない配信内容、時刻、人気、視聴者反応を推測・創作しないでください。

次の観点で上位5件を選んでください。

- 単独で内容が伝わる具体的な出来事か
- フリ、展開、反応または結論が理由文内で説明されているか
- 同じ出来事の重複候補ではないか
- 配信の通常進行だけを説明した候補ではないか
- **ゲーム内イベントは、Vtuber本人の特別な言動、強い感情反応、出演者同士の関係性を引き起こすきっかけになり得る。重要事件やクライマックスを一律に下げず、理由文に実際の言動・反応・関係性が表れている候補を優先する**
- ゲーム内イベントの規模だけで順位を上げない。Vtuber本人がそこで何をしたかが理由文から読み取れるかで判断する

尺、チャット数、笑い回数に点数や重みを付けないでください。合成点は返さず、順位と、人間が先に見る理由を1文だけ返してください。

出力はJSONだけにしてください。

```json
{
  "rankedCandidates": [
    {
      "rank": 1,
      "candidateId": 12,
      "reason": "この候補を先に確認する理由"
    }
  ]
}
```

制約:

- 5件ちょうど返す
- `candidateId` は入力に実在する整数だけを使い、重複させない
- `rank` は1から5の連番
- 入力にない時刻や数値評価を生成しない
