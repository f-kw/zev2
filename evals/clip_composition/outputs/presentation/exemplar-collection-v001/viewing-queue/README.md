## 返し方

動画ごとに、気づいた内容を自由文でこのチャットへ返す。時刻、強度、分類、時間計測は不要。実行部隊が整理して採集台帳へ転記する。

特に知りたいのは次の二つ。

1. 何が起きた瞬間に、どんな演出を使ったか。
2. その演出は他の題材にも使える一般的な文法か、その動画だけの作者固有の着想か。

1作品だけの固有ギミックは価値を否定せず参考として残すが、AI演出文法にはしない。
