# 演出のお手本採集 v001

開始日: 2026-07-18

目的: 実在の切り抜きを普段どおり観ながら、演出が「何に反応して発火したか」を少数の実例として残す。

使い方:

- 好きな1本だけ観ればよい。順番も期限もない。
- 全演出を拾わず、気づいたものだけ書く。
- 第一観点は、発話をどう区切り、いつ、どんな見た目のテロップで楽しく読ませているか。派手な特殊効果は目についた場合だけでよい。
- Markdownを編集せず、会話へ「動画ID / 時刻 / 種類 / 何が起きたか / 強度」を返してもよい。
- 強度は `弱 / 中 / 強`。作品の点数ではない。
- 内部の間引きは、気づいたときだけ任意表へ書く。

## 横断メモ: テロップの暫定目標

これは視聴済み本数には数えない人間の設計仮説である。

- 演出の主成分は、派手な効果よりも発話テロップの区切り・タイミング・見た目にある可能性が高い。
- 発話を、意味が読める短い単位のテロップで見せる。
- 文字サイズは一定かつ可能な限り大きくし、横幅を十分に使う。
- 長い場合は縮小せず、意味の切れ目で改行する。
- 発話に対応する読めるタイミングで、小気味よく切り替える。
- 読みやすく美しいフォントと枠線・縁取りを使う。
- リスナーコメントの読み上げは通常発話と区別し、背景板（座布団）+未設定プロフィールアイコン+コメント本文で、コメント欄の一項目として見せる。
- 弱々しい発話には、基本文字サイズを変えず、弱々しさが伝わるフォント表現を対応させる。具体的な字体・太さ・輪郭・色は教師実例で確認する。
- 内容のあるトークでは、背景板（座布団）を継続表示し、その上のテキストだけを発話に合わせて切り替える方式を、通常テロップのバリエーションとして持つ。
- 数値条件はまだ決めず、下記の教師実例で検証する。
