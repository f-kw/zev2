# 演出のお手本採集 v001

開始日: 2026-07-18

目的: 実在の切り抜きを普段どおり観ながら、演出が「何に反応して発火したか」を少数の実例として残す。

使い方:

- 好きな1本だけ観ればよい。順番も期限もない。
- 全演出を拾わず、気づいたものだけ書く。
- 第一観点は、発話をどう区切り、いつ、どんな見た目のテロップで楽しく読ませているか。派手な特殊効果は目についた場合だけでよい。
- Markdownを編集せず、会話へ「動画ID / 時刻 / 種類 / 何が起きたか / 強度」を返してもよい。
- 強度は `弱 / 中 / 強`。作品の点数ではない。
- 内部の間引きは、気づいたときだけ任意表へ書く。

### 観測の紐づけ規則

- 教師視聴メモを受領したら、動画別の発火点表へ記録したうえで、該当仮説の「紐づく観測」へ `裏付け観測: 動画ID @ HH:MM:SS` または `反例観測: 動画ID @ HH:MM:SS` を追記する。
- 同じ仮説に裏付けと反例の双方があれば、両方を削除せず残す。
- 観察で仮説どおりの関係を確認できた場合は「裏付け済み」へ昇格する。反例を確認した場合は「修正待ち」とし、元の仮説文を消さず、修正版を別履歴として残す。
- 既存14項目に当てはまらない観測も動画別表へ残し、5〜10本後の蒸留で新規候補として扱う。
- 数値条件はまだ決めない。
