# 第2版蒸留の反復判定・再設計案

## 提案

Geminiによる8本一括の出現マトリクス作成は打ち切り、**人間の66観測を肯定例だけとして扱う第2版蒸留**へ戻す。

1. 人間メモに書かれた演出は「その動画で観測済み」とする。
2. 書かれていない演出は「不在」ではなく「未確認」とする。新奇性へ偏る自由観察の性質を、そのまま欠測として明記する。
3. 2動画以上で人間が記録した関係だけを反復候補にする。ただし反復だけで文法へ昇格させず、複数の作風をまたぐ一般関係かを人間認定へ戻す。
4. 1動画だけの観測はstyle実例または保留へ置き、反復が無いと断定しない。
5. AI対象境界は既定案どおり、既存映像への装飾を対象候補、静止画・キャラクター素材からの独自画面再構成を品質上界の参考・当面対象外として、人間認定の問いにする。
6. 観測から答えられない優先順位、フォールバック、統一規則、数値条件は「観測不足」と記す。

この案は反復条件を数字だけ緩めるものではない。「記録がない=出現しない」という誤った陰性を作らず、正本から確認できる肯定例だけで蒸留するための変更である。

## Gemini補助の扱い

- 今回の`gemini-web-flash`出力は正本外の補助観測として保持する。
- 残り7本の照合と、差分候補の人間三択は行わない。
- 将来もう一度試す場合は、24種類一括ではなく、人間観測1件ごとに「この具体的な関係が別動画にあるか」を最大5件ずつ照合する別設計が必要。ただし今回の作業では再実走しない。

## 次に人間へ求める判断

この再設計で第2版蒸留案を起草してよいか、1件の承認だけを求める。承認後の蒸留認定質問は、従来どおり1セッション5問前後に分ける。

今回の必須人間作業は、この承認1件のみ。動画の再視聴は要求しない。
