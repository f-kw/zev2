# Gemini出現照合パイロット評価

## 結論

**不合格。残り7本へ展開しない。**

- 人間正本: 14観測
- 事前合格条件: 同じ意味の演出を時刻付きで7件以上再検出
- 厳密一致: **2/14**
- 大分類までは近いが、対象場面または具体的な演出が一致しない: **7/14**
- 未検出: **5/14**

大分類の`present`だけでは一致に数えていない。たとえば、Geminiが「文字造形あり」と答えても、人間観測の「来ないで！気持ち悪いわ、で文字を振動」に対応する発話・時刻・動きが揃わなければ不一致とした。

## 失敗の意味

Geminiは「この動画には文字造形やSEがある」といった**動画全体の大分類**は多く返した。一方、人間観測が必要としているのは「どの意味・話し方に、どの見た目を対応させたか」という**発火点単位の関係**である。現在の24種類一括照合では、一つの大分類に複数の人間観測が畳み込まれ、最大3時刻の出力では個別の反復確認にならなかった。

また、次の誤対応を確認した。

- `P04`: 静的な立ち絵を話者識別とし、人間観測の「2人分の同時テロップ」を代替してしまった。
- `R02`: ゲーム画面への通常の立ち絵・コメント欄合成を「独自画面の再構成」とし、装飾と再構成の境界を広く取りすぎた。

これは人間正本の誤りではなく、Gemini補助を反復確認へ使う現在の質問単位が粗すぎるという結果である。出力はモデル名付きの補助観測として保存するが、人間正本、反復数、蒸留根拠には加えない。
