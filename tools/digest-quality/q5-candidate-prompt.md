# Q5-1：同じ保持場面の説明の重複を検討する実判断

あなたは現行Codexの判断担当です。保存された入力とこの判断文を用い、実際の字幕・発話文脈から候補を判断してください。模擬回答や架空の成功例を作りません。

## 目的と対象

入力はC-allの全325字幕、12保持場面の文脈、保存ASR462区間と語時刻です。同じ保持場面内で近接する二つの発話が実質的に同じ説明を伝え、一方を省いても必要情報が残る可能性がある候補を探します。全体を読み、見つけた候補と関連文脈だけを保存します。字幕ごとの325行の監査表は不要です。

原版は完成済みで、新案は未採用です。短くすることを成功目標にせず、原版に欠陥があると先に決めません。保持理由も元版の意図として読み、無視せず、正解として追認もしないでください。

## 検討の条件

- 「残す説明」と「省く説明」を対で具体的に示す。
- 共通内容、省略側固有の数字・条件・否定・例外・結論、前後の参照・オチ・伏線を確認する。
- 驚き・笑い・呼びかけ・感情を強める反復は今回の対象外。
- 同じ語、長さ、無音、低音量、同じ演出だけでは選ばない。類似度スコア・重み付きランキングは使わない。
- 一保持区間内部の一連続範囲の省略で成立する候補だけを優先する。場面全体の削除、並替え、別場面からの追加、新しい演出はしない。
- 残す字幕の本文・改行・表示長を変えず、字幕や語の途中を切らない見込みがあるか確認する。
- ASRの文面は認識誤りを含み得る。確定字幕と食い違う場合は不足として記録する。
- ASRの秒数を正確な切断frameと認定しない。実切断位置は後段でPCM・保存境界等に照合する。
- 映像は意味的に観測しておらず、音を聴いた自然さ評価もしていない。新しい映像上の出来事や演技的反復を失う可能性を残し、「情報を何も失わない」と断言しない。

候補が複数あれば、残す／省く情報を具体化できること、一場面内、途中を壊さず切れる見込み、短い同文脈比較ができることから今回の一案を推奨してください。数のノルマはありません。根拠が成立しなければ候補0を正直に返してください。

## 渡していないもの

過去の具体演出ラベル、過去の人間品質回答、Q3の改善仮説、今回の比較動画は入力していません。これらを探しに行かず、候補の根拠にしないでください。新しいAPI、外部動画・音声・frame入力、視聴、モデル取得は行いません。
